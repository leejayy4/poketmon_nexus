## 완료 판정 규칙

- 도시 하나의 완료 조건은 [DEVELOPMENT 제0절의 여섯 축](DEVELOPMENT.md#도시-하나의-완료-조건)을 따른다. 맵·거리·연결 / 스토리·세계관 / 포켓몬·생활 / BW·BW2풍 표현 / 플레이·지속성 / 최종 QA·인계.
- **네 지방 중 하나라도 필수 구현이나 검증이 남아 있으면 이 Goal을 완료로 표시하지 않는다.** 맵 개수·크기·문서 작성량·조사 기록을 구현 진척으로 대신하지 않는다.
- 최신 범위의 고려 4체육관·연작·후일담도 전체 완료 판정에 포함한다. ‘선택 사건’은 플레이어가 고르는 진행 방식이며 제작 범위 제외가 아니다. 기존 C1~ 공통 시스템 번호·현재 도시 배정은 보존한다.
- QA 중단 지침은 유지한다. 개발 중에는 [상세 AGENTS의 최소 확인](AGENTS.md#검증과-도시-완료) 범위인 타입검사·대상 검사만 수행하고, 도시 QA·브라우저 플레이·음향·저장 재접속은 별도 재개 지시 전까지 미검증으로 기록한다.
- 공통 시스템(포켓몬·기술·아이템·전투·저장·PP)은 지방마다 복제하지 않는다. 사용자 실제 저장과 다른 작업자의 미커밋 변경을 보존한다. 커밋·푸시·의존성 추가·대규모 재작성은 하지 않는다.
