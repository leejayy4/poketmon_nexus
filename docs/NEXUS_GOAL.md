# Pokémon NEXUS — 비전·범위·결정

2026-09-22 재정립. 이 문서는 **무엇을 만들지와 채택한 제작 결정**만 관리한다. 현재 사실은 [PROJECT_STATE](PROJECT_STATE.md), 다음 작업은 [STORY_AXIS_ROADMAP](STORY_AXIS_ROADMAP.md), 기술은 [DEVELOPMENT](DEVELOPMENT.md)가 담당한다. 외부 앱의 Goal·자동화 상태를 이 문서로 선언하거나 변경하지 않는다.

## 작품의 약속

DS 시절의 여행 감각을 살린 싱글플레이 포켓몬 RPG다. 탐험·포획·육성·진화·배틀·체육관·리그와 주민·라이벌·동료의 일상이 하나의 여행으로 이어진다. 표현 목표는 [BW·BW2풍](VISUAL_STYLE_BW_BW2.md), 지리 대조는 신오 Pt / 관동·성도 HGSS / 하나 BW2다. 시각 목표와 전투 세대는 별개다.

주인공은 신오 챔피언을 꿈꾸며 출발해 다른 지방과 사람을 만난다. 서진·서연·아크·3초 공백은 장기 인과를 연결한다. 모든 전설과 포켓몬의 삶을 아크의 실험으로 설명하지 않는다. 독립적인 모험과 생태, 피카츄 마을·따라큐·붉은 갸라도스·파이리 등 관계 이야기도 작품의 필수 제작 범위다.

## 확정된 전체 범위

**신오 8배지·사천왕·챔피언 → 관동 8배지·사천왕·챔피언 → 성도 8배지·사천왕·챔피언 → 하나 8배지·사천왕·챔피언 → 신오 귀환·넥서스 최종장 → 집으로 귀환.**

- 본편은 32배지·4리그다. 기존 신오 네 배지 출항은 현행 코드의 과도기 계약이며 완성 게임의 본선 종료점이 아니다.
- 고려는 엔딩 뒤 서울·경주·부산·탐라의 **4배지·지역 대표 결승** 여행이다. 별도 사천왕은 없으며 전체 배지는 36개다.
- 본편 28장, SQ01~16, EX01~20, 파이리와 생활 연작, 재방문·후일담을 보존한다. 플레이어 선택 콘텐츠도 제작 범위에 포함된다.
- 신규 사슴·늑대·물범 스타팅 방향, 다섯 과거 회상, 주인공의 여행 중 후천 노출, 서연의 기억 잔향, 서진의 생환과 책임, 하나의 본편 결말을 유지한다.
- 상세 인과와 폐기 설정은 [확정 서사](story/NEXUS_MAIN_STORY_CANON.md)가 유일한 기준이다. 본편·연작·고려·대본은 그 기준의 상세 원고다.

## 재정립의 의미

기존 진행률·파일 수·도시 수를 새 제작의 출발점으로 삼지 않는다. 기존 코드는 **재사용 후보 자산**이며, 실제 구간에서 쓸 수 있는 부분을 선정한다. 채택 서사는 설계 입력으로 보존한다. 새 제작은 작은 완결 구간에서 다시 증명한다.

재정립 회차의 산출물은 문서 재편·정적 감사·실행 가능한 제작 계획이었다. 이후 사용자 지시로 HYBRID 구현에 착수했으며 실제 반영·미검증 범위는 PROJECT_STATE에서 관리한다. 작업 트리의 기존 미커밋 구현과 루트 AGENTS 삭제를 보존한다.

추천은 후속 제작의 출발안이며 채택된 사실로 위장하지 않는다. 여기의 선택을 기다리며 문서 정리나 독립적인 저장 보호 설계를 멈추지 않는다.

## 완료의 의미

문서 재정립은 **진입점·권위·현재 근거·다음 작업이 연결되면 완료**다. 첫 구간, 신오, 전체 NEXUS의 완료는 각각 별도다. 도시 수용은 [제작 계약](MAP_STORY_DESIGN.md), 첫 구간 수용은 [FIRST_BADGE_SLICE](FIRST_BADGE_SLICE.md)를 따른다.

전체 작품은 네 지방 본편·최종장·고려·채택 연작·후일담의 필수 구현과 검증이 남아 있는 동안 미완료다. 현재 이 조건을 충족하지 않았다.

이전 C번호의 처리는 [현행 로드맵](STORY_AXIS_ROADMAP.md#이전-c번호계획의-처리), 과거 결정은 [결정 이력](archive/DECISION_HISTORY.md)에서 확인한다. 중복 목표 사본은 삭제했다.
