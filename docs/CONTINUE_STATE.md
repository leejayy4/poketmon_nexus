# 다음 작업을 위한 짧은 인계

2026-09-22 — **초기 이벤트 등록 + NEXUS 새 게임·스타팅·첫 친선전 코드 연결. 실행 수용 미완료.**

1. [현재 상태](PROJECT_STATE.md)·[로드맵](STORY_AXIS_ROADMAP.md)을 기준으로 이어간다. 재정립 진단이나 문서 정리를 다시 시작하지 않는다.
2. RB1 보호는 유지한다. 기본 키/활성 포인터/원문 격리 계약은 [DEVELOPMENT §5](DEVELOPMENT.md#5-저장-계약과-안전한-이행). 기존 v1은 동료·진행 그대로, Engine 새 게임은 v2 `campaign:nexus`+프로필이다. `newSave()`는 구형 테스트/호환 생성기이며 `newNexusSave()`와 다르다. worldRevision24·배지4·Lv25는 유지한다.
3. RB2: `first-journey-events.ts`의 map+event 등록을 Engine의 도로 트레이너 뒤/도시 폴백 앞에 연결했다. 축복 시계·입구/귀환·게이트·강석·탄갱·전시관·첫 배지 밤이 기존 어댑터를 사용한다. city/sinnoh의 중복 호출은 제거. 축복 다음 길은 203, 배지 뒤는 204·험한샛길·꽃향기로 안내한다.
4. RB3: 프로필 → 중계 → 가족 엽서 → 은솔/하린 → 세 종 선택 → 실제 연구소 밖 첫걸음 → 기존 귀가 소개/산책 → 도윤 보급 → 유진 선택 친선전. 새록900001/잿울900002/포말이900003은 **잠정 제작안**이며 공식 전국번호를 재사용하지 않는다. 앞/뒤 SVG와 런타임 데이터/PP/성장을 연결했으나 최종 디자인·진화/애니메이션 수용은 아니다.
5. 다음 가까운 작업은 **잔모래 센터에서 유진과 첫 여행을 돌아보는 재회**, 그리고 201·호수·잔모래·202의 포획/회복/성장 안내를 새 세 동료에 맞춰 닫는 것이다. 현재 친선전은 도윤의 응급 처치로 종료하며 센터 방문을 가짜로 기록하지 않는다. 시작은 기존 새잎 `town/lab` 재사용 중이고 떡잎/잔모래의 최종 역할 이행도 남아 있다. 이후 세 스타팅의 강석 준비 경로를 소스·현지 선택지와 함께 검토한다.
6. **QA 중단 유지.** 테스트·타입검사·빌드·브라우저·게임·실제 저장·시청각 검증은 실행하지 않았다. 새 `first-journey-events`, `nexus-opening`, `nexus-starters`, `nexus-first-rival` 회귀 파일은 작성만 했다. 재개 후 저장 보호/구형 사본, 새 이름 입력·취소·복구, 세 선택 각각의 자연 진행/친선전 승패·중단/귀환부터 검사하고 도시와 전체 slice 수용을 구분한다. 기존 Engine 검사는 구형 fixture의 panel/factory 계약도 확인한다.
7. 실제 사용자 저장은 읽거나 수정하지 않았다. 기존 미커밋/미추적 구현·문서 재편·루트 AGENTS 삭제를 보존했다. 스타팅 데이터는 기존 캐시로 `export-runtime-pokemon.py --offline` 생성했고 다운로드하지 않았다. 서버·자동화·커밋·푸시·의존성은 변경하지 않았다.
8. 참고 원문과 채택/변경/제외 이유는 [참고 기록](reference/REFERENCE_RESEARCH.md), 입력/출력 책임은 [데이터 계약](RUNTIME_DATABASE.md)을 따른다. 외부 코드·신규 외부 자산 복사는 없다.

코드·정적 검토를 완료/PASS로 간주하지 않는다. 구형 저장 이행·새 스타팅 도입·첫 여정 자연 진행은 각각 검증 근거가 필요하다.
