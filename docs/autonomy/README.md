# 회차별 구현·검증 이력

이 폴더의 날짜·회차 보고는 당시 변경·검증·실패·다음 후보를 보존한다. 보고에 있는 ‘매 작업 검증’, ‘3회차 QC’, ‘첫 배지 우선’, 역할별 수정 금지, 자동화 ACTIVE 표시는 현행 작업 지시나 현재 운영 상태의 증거가 아니다.

현재 개발 목표·도시 완료 조건은 [DEVELOPMENT 제0절](../DEVELOPMENT.md#0-최우선-목표와-지방도시-작업-단위), 검증 시점은 [도시 완료 후 QA](../AGENTS.md#검증과-도시-완료), 현재 지방·도시·저장은 [CONTINUE_STATE](../CONTINUE_STATE.md)를 따른다. 관련 구간의 기존 증거가 필요할 때만 해당 보고를 읽는다.

과거 실패·미검증·사본/자연 진행 구분은 보존한다. 현재 구현이 달라졌으면 기준 문서와 새 보고를 갱신하고 옛 기록을 현재 완료로 고쳐 쓰지 않는다.
