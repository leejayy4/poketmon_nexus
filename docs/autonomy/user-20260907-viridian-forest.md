## 문제와 수정

상록숲은 기존 가장자리 나무 한 곳과 넓은 십자형 길을 사용하는 짧은 연결 맵이었다. 중앙 군락 양쪽을 돌아 아래에서 합류하는 길과 나무 네 군락을 배치했다. 서쪽은 넓은 통과 길, 동쪽은 기존 안내원 옆 관찰 샛길이다. 나무 설명은 길과 풍경에 한정한다.

기존 맵·출구·복귀 좌표·안내원·스토리·도구·조우 조건을 유지한다. 기존 조사 ID 뒤에 네 개를 추가했다. 저장 개정 20으로 이전 저장의 새 나무 겹침만 같은 맵 `(10,10)`으로 보정한다. 저장 필드·새 사건·Pokémon Stories·아이템 보상은 추가하지 않았다.

변경 파일: `src/explore-layouts.ts`, `src/town.ts`, `tests/viridian-forest-layout.test.ts`, `tests/explore-layouts.test.ts`, `DEVELOPMENT.md` 68절, `STORY.md` 57절, `WORLD_TOUR.md`.
