# 관동 노랑시티 동부 접근 묶음

## 1단계 — 관동 8번도로

- 보라타운 서쪽과 노랑시티 동쪽의 기존 직결 통로를 일반 본선에서 분리하고 `tour_kanto_route_8` 관동8번도로64×28을 삽입했다.
- 보라 서쪽 기존 출구 `(1,12)`은 8번 동쪽 `(62,14)`/안전점 `(60,14)`, 노랑 동쪽 기존 출구는 8번 서쪽 `(1,14)`/안전점 `(3,14)`과 왕복한다.
- 중앙 무조우 본선, 보라 경계 꽃둑, 노랑 외곽 전광 안내, 도시 포켓몬 휴게 울타리, 동서 지하통로 동쪽 입구 경계를 배치했다.
- `tour_pass_saffron_lavender`는 그 맵에서 시작한 과거 저장의 양쪽 귀환을 위해 보존한다. 새 일반 진입은 8번도로를 사용한다.
- 1단계 당시 동서 지하통로·7번도로·무지개 경계와 야생 조우·트레이너·아이템·검문 잠금·실프 사건·체육관은 없었다.
- 모든 QA 중단으로 생성·워프·스폰·충돌·표지·과거 저장 귀환·화면·저장은 미검증이다.


## 2단계 — 관동 7번도로와 동서 지하통로

- `tour_kanto_route_7`48×24를 무지개 동쪽과 노랑 서쪽 사이에 삽입했다. 서쪽 `(1,12)`/안전점 `(2,12)`은 무지개, 동쪽 `(46,12)`/안전점 `(45,12)`은 노랑과 왕복한다.
- `tour_kanto_underground_ew`72×24를 7번 남쪽 `(24,20)`과 8번 남쪽 `(27,21)` 사이의 선택 우회로로 연결했다. 통로 출구는 서쪽 `(1,12)`/안전점 `(2,12)`, 동쪽 `(70,12)`/안전점 `(69,12)`이다.
- 지상 본선은 `무지개 → 7번도로 → 노랑 → 8번도로 → 보라`, 선택 우회는 `7번도로 → 동서 지하통로 → 8번도로`다. 노랑 관문은 자유 통행이다.
- 7번에는 무지개 정원 경계·노랑 업무 지구 안내, 지하통로에는 동서 색 노선띠·포켓몬 쉼터를 배치했다. 새 조우·트레이너·아이템·회복·보상·스토리 플래그는 없다.
- `tour_pass_celadon_saffron`과 `tour_pass_saffron_lavender`는 내부에서 시작하는 과거 저장의 도시 귀환용으로 보존했다. 검문 잠금·실프 사건·노랑 체육관은 채택하지 않았다.
- 모든 QA 중단으로 맵 생성·워프·안전점·충돌·표지·화면·과거 저장 귀환은 미검증이다. 다음은 노랑 외부64×64 업무·주거·역 구역 확장이다.


## 3단계 — 노랑시티 외부64×64

- `tour_saffron`을40×36에서64×64로 확대했다. 기존 중심부 센터 문 `(8,8)`, 실프 사옥 문 `(31,20)`, 상점·공동주택 건물 좌표를 고정했다.
- 동쪽 연구 휴게정원·업무 지구 시계 분수, 남서 공동주택 쉼뜰, 남쪽 성도행 열차 환승 광장, 남동 도시 완충숲과 순환 보행로를 추가했다.
- 서쪽 7번도로, 동쪽 8번도로, 남북 기존 연결과 성도 금빛역행 무료 열차 계약을 유지한다. 도착 안내판·연구 관찰대·동료 급수대·열차 환승 표석을 배치했다.
- 새 공간은 주민과 포켓몬의 업무·휴식·이동을 보여 주며 회복·보상·스토리 플래그가 없다. 실프 사건·도시 봉쇄·검문·체육관은 채택하지 않았다.
- 모든 QA 중단으로 크기·기존 좌표·출구·열차·충돌·조사 접근·화면·저장은 미검증이다. 다음은 센터28×22·실프 사옥 각층28×24·상점24×20·공동주택 각층24×18 적용이다.


## 4단계 — 노랑시티 필수 실내

- 센터28×22, 실프 사옥1~3층 각28×24, 상점24×20, 공동주택3동의 각1~3층24×18을 적용했다. 기존 MapId·외부 문·층간 계단·가구 이벤트를 보존한다.
- 센터는 동서 여행 지도·통근 동료 휴게·파티/PC 준비, 실프 사옥은 생활 장치 공개 전시→장치 안전 연구→도시 기술·교통 전시로 구분했다.
- 상점은 7·8번도로와 열차 전 보급을 다루며 판매 품목은 기존 몬스터볼·상처약이다. 공동주택은 통근 준비, 급수 관리와 생활 장치 수선, 금빛역 왕복과 지방 교류 생활을 층별로 나눴다.
- 실프 사옥은 공개 견학 범위다. 사건·점거·봉쇄·체육관, 새 아이템·회복·보상·진행 플래그를 추가하지 않았다.
- 모든 QA 중단으로 크기·문·계단·회복·PC·구매·조사 접근·화면·저장은 미검증이다. 다음은 실제 파티 상태와 7·8번도로·지하통로·열차 이동 이력을 안내원·주민·생활 포켓몬·조사점에 연결하는 단계다.


## 5단계 — 파티·이동 이력 기반 도시 생활

- `saffron-life.ts`를 추가해 노랑 외부와 모든 필수 실내의 생활 이벤트를 실제 파티 상태에 연결했다.
- 안내원·센터 지도는 7번도로·동서 지하통로·8번도로, 금빛역/금빛시티 방문 여부와 파티 건강·부상·기절 수를 읽는다. 센터·PC·실프·세 도보 구간·금빛역을 실제 목적지로 표시한다.
- 연구 휴게정원·공동 급수대·실프 공개 전시·세 공동주택·직장인·연구원·업무 거리 피카츄가 같은 상태에 반응한다. 피카츄는 주민과 사는 생활 개체다.
- 자동 이동·편성·회복, 새 저장 플래그·아이템·보상·통행 조건은 없다. 공개 견학은 실프 사건·점거/봉쇄·체육관 진행이 아니다.
- 모든 QA 중단으로 이벤트 접근·선택지·길안내·분기·화면·저장은 미검증이다. 다음은 7번도로·동서 지하통로·8번도로 전용 DP풍 필드 표현이다.


## 6단계 — 7번도로·동서 지하통로·8번도로 전용 표현

- `saffron-art.ts`를 추가하고 세 접근 맵을 `explore-art.ts`의 전용 렌더링 분기로 연결했다.
- 7번도로는 무지개 쪽 나무·꽃 경계에서 노랑 쪽 포장·가로등·업무 표식으로, 8번도로는 노랑 쪽 전광 업무 경계에서 보라 쪽 나무·꽃둑으로 변한다.
- 동서 지하통로는 밝은 바닥·어두운 벽, 서쪽 녹색/동쪽 보라색 노선띠, 천장 조명·환기구·동료 쉼벤치로 긴 방향을 구분한다.
- 맵 크기·워프·스폰·충돌·NPC·조사 이벤트는 변경하지 않았다.
- 모든 QA 중단으로 캔버스 생성·타일 정렬·색 구분·오브젝트 겹침·이동 화면은 미검증이다. 다음은 7·8번도로 선택 조우 생태와 선택 트레이너다.

## 7단계 — 7번도로·8번도로 선택 포획과 실전

- 7번도로 외곽 정원 풀밭 3곳에 `K-R07-DAY` 나옹55/구구45 Lv.23~25, 8번도로 외곽 풀밭 3곳에 `K-R08-DAY` 구구45/깨비참35/아보20 Lv.23~25를 연결했다. 현재 등록 종만 사용한 낮·도보 프로젝트 조정 풀이다.
- 양쪽 중앙 본선과 `tour_kanto_underground_ew`는 조우가 없다. 7번의 무지개↔노랑, 8번의 노랑↔보라, 7번↔지하통로↔8번 이동은 포획 없이 가능하다.
- 7번도로 `(30,19)`의 나옹23→구구24 트레이너는 첫 승리520원, 8번도로 `(35,20)`의 구구24→깨비참25 새잡이는 첫 승리540원이다. 두 전투는 거절 가능하고 배지·TM·통행 조건과 무관하다.
- 생성기는 소유 가능50종·조우22풀·기술53개를 출력했다. 이는 생성 실행 결과이며 QA 통과 근거가 아니다. 모든 QA 중단으로 풀밭 좌표·조우·포획·배틀·상금·승리 저장·재대화·안전 본선은 미검증이다.
- 다음은 노랑센터와 도시 생활 안내가 `met=관동 7번도로/관동 8번도로`의 파티·PC 동료 및 두 트레이너 승리 기록을 읽고 편성·회복·다음 이동으로 잇는 단계다.

## 8단계 — 현지 동료 편성·회복·재도전 연결

- 노랑 안내원·7/8번 도착 안내판·센터 여행 지도/휴게석/준비 단말·실프 공개 전시·공동주택 생활 기록이 파티와 박스의 `met=관동 7번도로/관동 8번도로`를 집계한다.
- 도로별 보유 수, 현재 파티의 현지 동료 수, 최대5종과 `trainerWon:kanto-route-7-practice`/`trainerWon:kanto-route-8-practice`를 표시한다.
- 센터에서 현재 파티, PC 편성, 7번 정원 풀밭/남쪽 트레이너 공터, 8번 외곽 풀밭/꽃둑 트레이너 공터를 실제 목적지로 표시한다. 자동 이동·편성·회복·재보상은 없다.
- 현지 동료가 없거나 PC에만 있어도 도시·도로·지하통로·열차·실프 공개 견학은 막히지 않는다. 실프 전시는 현지 종의 체형과 야외 반응을 생활 장치 설명에 대조할 뿐 능력이나 플래그를 바꾸지 않는다.
- 모든 QA 중단으로 출처 집계·파티/PC 분기·승리 상태·선택지·목적지·저장은 미검증이다. 다음은 노랑 담당 구현 누락의 소스/문서 대조다.

## 9단계 — 노랑 담당 구현 완료 후보 대조

- 외부64×64, 센터28×22, 실프 사옥1~3층 각28×24, 상점24×20, 공동주택3동 각1~3층24×18의 크기 계약과 생성 연결을 대조했다.
- 서쪽7번도로48×24, 동쪽8번도로64×28, 두 도로 남쪽의 동서 지하통로72×24가 정확한 출구·안전점·귀환으로 기록돼 있다. 북쪽 블루 축약 연결과 남쪽 금빛역 무료 열차도 유지한다.
- 안전 본선/선택 풀밭, 현지 포획→PC 편성/간호사 회복→선택 트레이너→도시 생활/실프 공개 견학→다음 출구가 현재 채택 범위에서 소스로 연결되어 노랑 담당을 구현 완료 후보로 둔다.
- 실프 점거 사건, 체육관·배지·TM, 검문 봉쇄, 독립5/6번도로는 미확정 또는 후속 범위다. 완료 후보에 포함하지 않는다.
- 모든 QA 중단으로 워프·충돌·포획·배틀·상금·저장·화면·음향은 미검증이며 도시 완료/PASS로 판정하지 않는다. 다음 관동 담당은 무지개시티 외부72×64와 연결 경계다. 공유 7번도로는 현재 상태로 보존한다.
