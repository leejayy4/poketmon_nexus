# 봉신 기술 준비 동료의 실제 출전 연결

- 변경: sinnoh-celestic-life.ts에서 공통 기술 화면 귀환 후 선택한 동료를 명시적으로 선두에 세울 수 있다. 공통 leadPokemon을 재사용하여 실제 파티 순서/필드 동료 추적/저장을 갱신한다. 기절은 기존 함수가 거부하고 간호사를 안내한다. 취소하면 기존 편성을 유지한다.
- 누락: 기존 기술 준비는 partyIndex만 선택하여 기술을 바꿨고 선두는 그대로였다. 새 행동은 기술 준비한 동료의 실제 다음 전투 출전을 연결한다. 이후211 동부 트레이너 또는 여행 지도 안내를 선택한다. 다른 동료와 출발하는 선택도 보존한다.
- 2026-09-15 보완: 출발 목적지의 211 동부 고정을 제거했다. `met`이 210 북부·211 서부·211 동부이면 해당 장소의 미완료 선택전으로 돌아가고, 이미 승리했다면 다음 연결 구간 또는 재방문 표지로 간다. 천관산 통과층 동료는 동·서부의 남은 선택전을 우선하고 모두 마쳤으면 통과층 관찰로 돌아간다. 다른 장소에서 만난 동료는 봉신 여행 지도로 돌아가 플레이어가 목적지를 고른다.
- 원작/프로젝트: 기존2026-09-13 직접 열람 자료 https://www.serebii.net/pokearth/sinnoh/4th/route211.shtml 와 https://bulbapedia.bulbagarden.net/wiki/Celestic_Town 의 Pt 도로 도전/센터 역할을 참고한 프로젝트 준비 흐름이다. 새 원작 기술 전수/보상/강제 출전 사건이 아니다.
- 소비: 기존 showMoveSchool 귀환 콜백→leadPokemon→trackFieldPartners→persist. 공통 engine/renderer/adventure-guide/catalog 및 오프닝 파일 변경 없음. 새 중앙 export 불필요.
- 검증: 모든 QA 중단. 소스 반영·미검증. 실제 교대/기절/취소/전투 선두/기술 사용·저장 복원 확인은 남아 있다. 이번 묶음 종료.
