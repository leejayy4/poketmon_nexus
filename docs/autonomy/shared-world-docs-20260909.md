## 남은 문제와 다음 작업

번호·도로/동굴 분할·수상/승선 표현의 게임 반영은 각 지방 문서의 후속 구현 범위다. 원작 지리를 비교했다고 프로젝트 번호를 바꾸거나 원작 도로를 전부 복원하도록 승인한 것은 아니다. 전체 DB의 원작 사실을 모든 행 공식 대조한 결과도 아니다.

현재 게임 재개 위치·마지막 통합 QC·이후 구현 회차 수·다음 태초→홍련 작업은 [CONTINUE_STATE](../CONTINUE_STATE.md)를 그대로 유지한다. 이 문서 회차는 구현 횟수에 포함하지 않는다. PROJECT_STATE 배정/사용자 저장은 변경하지 않았다. 별도 지역 문서 작업의 변경을 보존했다.
