# 관동 보라타운 도착 묶음 — 블루 경계부터 구현

## 1단계 — 관동 9번도로

- 블루시티 동쪽 경계에 `tour_kanto_route_9` 관동 9번도로를 목표 크기72×32로 추가했다. 블루의 기존 세 출구는 유지하고 새 동쪽 출구 `(38,12)`를 9번도로 서쪽 `(1,16)`, 진입 안전점 `(3,16)`과 연결했다.
- 굴곡진 고지 본선, 턱 아래 남쪽 우회로, 상단 전망 순환로를 서로 재합류시켰다. 턱길 안전 표석, 동부 고지 전망대, 터널 전 준비 쉼터, 10번도로 방향 경계석으로 다음 구간과 귀환 방향을 표시한다.
- 발전소는 10번도로 북부의 수역 선택 분기지만 수상 이동 지원이 없으므로 워프·접근로·이용 가능 안내를 추가하지 않았다.
- 9번도로에는 런타임 조우 풀, 풀숲, 트레이너 전투, 아이템·보상·진행 조건을 추가하지 않았다. 이 단계에서 미완성이던 동쪽 끝은 아래 2단계에서 `10번도로 북부32×56`과 연결했다.
- 당시 다음 구현은 9번도로 동쪽 → 10번도로 북부 → 돌산터널 입구 순서였다. 사용자 지시에 따라 좌표·충돌·왕복·미니맵·화면은 QA하지 않았다.

## 2단계 — 관동 10번도로 북부와 터널 앞 회복 거점

- 9번도로 동쪽 `(70,17)`과 `tour_kanto_route_10_north` 남쪽 `(16,54)`을 연결했으며 10번도로 진입 안전점은 `(16,52)`다. 32×56 안에 긴 오르막 본선, 센터 앞 순환로, 발자국 관찰터, 발전소 수역 전망 난간, 터널 앞 점검대를 배치했다.
- 산행객과 그 동행 피카츄가 암벽 소리를 살피고 짐을 점검하는 생활 장면을 넣었다. 이 피카츄는 야생 조우가 아니며, 10번도로에는 근거가 확정된 런타임 조우 풀·풀숲·트레이너 전투를 추가하지 않았다.
- `tour_kanto_route_10_north_center` 포켓몬센터28×22는 외부 현관 `(7,36)`과 실내 출구 `(14,21)`·안전점 `(14,18)`으로 왕복한다. 간호사 회복, 산길 회복 장치, 터널 안내 PC, 큰 동료도 쉴 수 있는 휴게석을 두었다.
- 발전소는 물 건너 전망만 가능하고 워프·수상 이동·이용 조건은 없다. 북쪽 돌산터널은 입구와 안내만 있으며 다음 단계에서 1F/B1F MapId를 연결한다.
- 새 아이템·보상·플래그·진행 잠금은 없다. 모든 QA 중단에 따라 좌표·충돌·회복·저장·화면·음향은 실행 확인하지 않았다.

- `tour_kanto_rock_tunnel_1f`와 `tour_kanto_rock_tunnel_b1f`를 각각56×48로 구현했다. 1F 남부와 북부는 분리되어 있으며 B1F 본선을 통과해야 서로 오갈 수 있다.

- 입구 자연광, 암반 긁힌 자국, 밝은 광물 안전 표식, 물방울 쉼터를 배치했다. 플래시 기술이 없는 현재 기능을 막는 조건으로 쓰지 않고 양방향 표식으로 길을 읽게 했다.
- B1F 산행객과 동행 알통몬은 동굴 생활 장면이며 야생 조우가 아니다. 런타임 조우 풀·트레이너 전투·아이템·보상·스토리 플래그는 추가하지 않았다.
- 다음 구현은 1F 북부 출구 → 10번도로 남부28×48 → 보라타운 북쪽 도착 경계다. 모든 QA 중단에 따라 이동·계단·충돌·화면·음향·저장은 미검증이다.

- 모든 QA 중단에 따라 조우 지형 접근·안전 본선·발생률·포획 `met`·도감/PC·트레이너 시작/거절/패배/승리·상금·재대화는 미검증이다. 다음은 보라센터·추모탑 안내를 현지 포획 종과 트레이너 결과에 연결하는 단계다.


## 10단계 — 현지 포획·편성·실전·도시 기록 연결

- 보라센터 여행 지도는 파티와 PC에서 `관동 9번도로`, `관동 10번도로 북부`, `관동 10번도로 남부`, `돌산터널 B1F` 출신 동료를 찾는다. 전체 보유 수, 현재 파티 수, PC 수와 최대5종을 보여 주며 과거 다른 장소에서 잡은 같은 종은 현지 포획으로 세지 않는다.
- 지도는 9번도로·돌산터널B1F·10번도로 남부 선택 트레이너의 승리 플래그를 읽어 승리 수와 장소를 표시한다. 현재 파티 화면, 센터 PC, 세 선택 활동 위치를 직접 안내하지만 자동 편성·회복·이동은 하지 않는다.
- 추모탑2층 돌봄 기록은 현지 동료와 현재 파티의 부상·기절 상태를 함께 읽는다. 3층 방문 수첩은 최대5종과 선택 배틀 결과를 표시하고 기존 `lavenderReflectionLogged` 비보상 기록에 포함한다.
- 새 포획 조건, 자동 PC 조작, 경험치·아이템·돈·배지·통행 보상, 유령·로켓단 사건 플래그는 추가하지 않았다.
- 모든 QA 중단에 따라 현지 `met` 집계, 파티/PC 메뉴 전환, 목적지 표시, 승리 플래그 분기, 수첩 반복 기록, 저장과 회복 비변경은 미검증이다. 다음은 보라 담당 완료 기준과 미채택 원작 사건을 대조해 QA 전 필수 구현 누락을 정리하는 단계다.


## 11단계 — 확정 이야기 연결·완료 기준 대조

- 맵 크기 대장과 생성 코드를 대조했다. 보라40×36, 9번72×32, 10번 북부32×56/센터28×22, 돌산터널1F/B1F 각56×48, 10번 남부28×48, 보라 센터28×22·탑 각28×24·상점24×20·주택 각24×18이 목표값과 일치한다.
- 공식 9→10북→돌산터널→10남 왕복, 안전 본선과 선택 조우/트레이너, 현지 포획→센터 편성/회복→실전→추모 기록, 외부·실내 전용 표현이 연결되어 현재 채택 범위의 필수 구현은 소스상 채워졌다.
- 보라 안내원·센터 지도·추모탑 수첩이 `researchDelivered`/`ferryPass`를 읽는다. 자료 전달·조사선 뒤 관동을 여행 중인지 설명하지만 보라 방문을 3초 현상 해결이나 다음 본편 사건으로 만들지 않는다.
- 갈색 귀환은 `보라 → 10번도로 남부 → 돌산터널1F/B1F → 10번도로 북부 → 9번도로 → 블루 → 5번도로 → 남북 지하통로 → 6번도로 → 갈색`으로 안내한다. 조사선은 갈색항의 기존 별도 선원과 `researchDelivered` 계약을 따른다.
- 실프 장비 사건·뮤츠 구조·등나무노인/로켓단·보라 체육관·따라큐 수선방은 초안 또는 후속 미채택 범위로 남기며 이번 완료 후보에 포함하지 않는다.
- 모든 QA 중단으로 이동·조우·전투·저장·화면·음향을 확인하지 않았다. 따라서 보라 담당은 **구현 완료 후보/QA 보류**이며 PASS가 아니다. 다음 관동 단위를 선택할 때까지 보라에 반복 안내나 전시를 더 추가하지 않는다.
