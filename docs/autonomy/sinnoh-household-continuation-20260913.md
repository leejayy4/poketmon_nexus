# 봉신 생활시설 외관·현장 활동 연결 — 2026-09-13

## 변경

- `src/sinnoh-celestic-art.ts`: 기존 공통 전경 호출에 연결된 `paintCelesticRuinsFacade`가 상점·전승가옥도 처리한다. 상점은 낮은 지붕·줄무늬 차양·진열창·물품 상자, 전승가옥은 계단형 박공지붕·서가 창·창살을 가진 별도 형상으로 구현했다. 단순 색상 교체가 아니다. 돌출물은 기존 건물 경계 안에 두며 문과 바닥턱은 기존 warp 좌표를 사용한다. 센터와 유적은 기존 표현을 유지한다.
- `src/sinnoh-celestic-life.ts`: 센터 여행 지도에서 파티/현지 동료 상태와 기존 PC·천관산 관찰·210 북부 여행자로 실제 `setTourDestination` 길안내를 제공한다. 상점 보급 선반은 현재 볼·약 재고를 읽고 판매 카운터와 센터로 안내한다. 전승가옥 옛 지도는 기존 동료·지층 기록에 따라 남은 암반 또는 유적 표본으로 안내한다.
- 천관산 안내원 재대화 시 동료 선택을 다시 열어 부분 관찰 기록을 초기화하던 흐름을 수정했다. 기존 동료가 있으면 남은 지층으로 이어가며, 동료 재선택을 명시적으로 선택했을 때만 기존 선택 로직으로 들어간다. 기절 동료는 센터로 안내한다.
- 실제 호출: 기존 `explore-art.ts`의 봉신 전경 dispatch와 `journey-services.ts`의 `handleSinnohCelesticLife`를 그대로 소비한다. 추가 공통 연결은 없다.
