## 도구 문제·미검증

- 브라우저 관찰 도구에서 localStorage를 직접 읽으려던 시도는 해당 객체가 노출되지 않아 실패했다. 이후 공개 UI 파일 내보내기/가져오기와 DOM 상태만 사용했다. 게임 오류가 아니다.
- 코드 HMR로 가져오기 대기 상태가 초기화돼 첫 로드 버튼 클릭이 비활성 상태로 거절됐다. 파일을 재선택한 뒤 정상 시작했으며 이후 전투 도중 HMR은 없었다.
- 내보낸 두 파일의 decodeSave 검증은 PowerShell 인라인 명령의 인용부호 전달 오류로 처음 실행되지 않았다. 표준입력 스크립트로 재실행하여 시작 블루(8,9)/steps2939와 최종 회색(24,11)/steps3151의 유효한 저장 해석을 확인했다.
- 실제 포획 실패·100% 포획·박스 만원·기절 경계는 이번 브라우저에서 재현하지 않았다. 자동 검사로만 확인했다.
- 두 조우만으로 모든 해안길 종/저레벨 파티의 반복 육성 난이도를 수용하지 않는다. 첫 배지 세 스타팅 반복 육성 부담도 미완료다.
