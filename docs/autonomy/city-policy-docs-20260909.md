# 지방·도시 단위 개발 정책과 문서 충돌 정리

2026-09-09 사용자 직접 요청. 문서·문서 생성 설명 전용 작업.

## 변경

- 우선 목표를 포켓몬 세계관에 맞는 Nintendo DS DP/플라티나풍 **맵·스토리 구현 및 실제 적용**으로 통일했다. 포켓몬 생태·주민·도시/지방 디자인·도로/동굴의 거리와 탐험 경험을 도시 완료 조건에 포함했다.
- [DEVELOPMENT 제0절](../DEVELOPMENT.md#0-최우선-목표와-지방도시-작업-단위)은 목표·우선순위·도시 완료 조건, [상세 AGENTS](../AGENTS.md#검증과-도시-완료)는 QA 시점, [문서 안내](../README.md)는 기준 문서별 책임·충돌 해결을 담당한다.
- 루트 AGENTS/README, STORY, 운영/배정/이어받기, 네 지방 기준, 공통 데이터/경로/지도, 플레이 안내, 첫 배지 기준과 장기 초안의 현행/과거 범위를 맞췄다. 생성 DB의 참조 링크와 생성기에도 같은 정책을 반영했다.
- 매 기능·3회차 QA 규칙을 폐기했다. 도시 구현 완료 후 검증을 모으고, 개발 중 실제 발견한 오류만 필요한 범위에서 확인·수정한다. 옛 회차 수·첫 배지 우선·역할의 코드 금지는 과거 기록으로 구분했다.
- 현재 관동의 태초→홍련 여행을 홍련섬 도시 단위 목표로 정리했다. 9번도로 진입 여행·홍련 외부/실내·확정 이야기/활동·포켓몬·귀환/다음 출구 경계를 포함한다. 실제 게임 위치와 기존 검증 증거는 보존했다.

## 검증

- 상위/지방/공통/초안 문서의 상대 링크와 앵커 868개 오류0.
- 활성 운영 문서에서 이전 QA 주기·강제 첫 배지 재시작·여러 도시 일괄 QA 지침의 잔여 충돌을 확인하고 수정했다. 과거 회차 보고는 이력으로 보존하며 현행 규칙을 상속하지 않도록 분리했다.
- 문서 생성기 Python 구문 검사와 기존 JSON만 사용한 DB 안내 렌더링 통과. 데이터 전체 생성·런타임 추출은 수행하지 않았다.
- `git diff --check` 통과. 작업 시작 스냅샷 대비 게임 소스·자산·테스트/저장·설계 JSON 1,154파일 변경0. 설계 Markdown 표 본문 변경0.
- 문서 전용이므로 게임 테스트·빌드·브라우저 QA는 수행하지 않았다. 도시 구현 완료나 새로운 자연 플레이 증거를 추가하지 않는다.

## 남은 작업

문서 정책 적용은 완료했다. 다음 게임 구현은 [CONTINUE_STATE](../CONTINUE_STATE.md)의 홍련 도시 목표를 이어 맵·스토리부터 적용한다. 번호·도시 확장·미확정 본편의 구현 상태는 각 지방 문서와 기존 코드 기준으로 구분하며, 이번 정리로 이미 적용된 것으로 바꾸지 않는다.
