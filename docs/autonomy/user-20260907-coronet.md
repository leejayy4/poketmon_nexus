## 문제와 수정

1. 실제 화면은 넓은 십자형 길과 작은 암석 두 개였고, 암석 그림 22×19픽셀에 비해 충돌은 32×32픽셀이었다. 기존 공간에 암반 세 곳과 굽은 흙길·호수 갈림길을 배치했다. 기존 암석 두 곳을 포함한 다섯 곳 모두 그림과 그림자를 충돌 바닥 범위에 맞추고, 불규칙한 윤곽과 돌의 층을 표현했다.
2. 북쪽 영원시티·남쪽 연고시티·동쪽 신오 호수로 연결되지만 안내원은 ‘서쪽으로 돌아갈 수 있다’고 말했다. 실제 세 출구와 풀밭을 피하는 방법을 안내하도록 수정했다. 회복·상처약 최소 2개 보충과 기존 이야기 조건은 유지한다.
3. 새 암반과 겹치는 이전 저장을 보호하도록 맵 개정 19를 사용한다. 기존 저장 이행 코드가 개정 18 이하의 막힌 위치만 `(10,10)`으로 옮긴다. 파티·HP·경험치·도구·플래그·배지·방문·걸음·시간은 보존한다.
