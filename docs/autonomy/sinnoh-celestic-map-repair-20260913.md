# 봉신 기존 지도 보수 — 2026-09-13

이번 중앙 요청의 QA 중단이 기존 문서의 재개 기록보다 우선한다. 테스트·빌드·브라우저·저장 검증을 실행하지 않았다. 지도 확대나 새 MapId 추가는 없다.

## 변경 파일과 원인

`src/sinnoh-celestic-art.ts`의 기존 `paintSinnohCelesticDetails`를 수정했다.

- 기존 봉신 유적 배경 직사각형은 `(16,6) 9×9`로 실제 건물 `(17,8) 7×7`보다 커 통행 가능한 앞마당을 덮었다. 배경의 중복 유적을 제거하고 등록된 현관으로 석재 보행축을 연결했다.
- 동쪽 숲 `(27,23) 8×10`을 회색 벽으로 칠하던 표현을 숲으로 교체했다. 나무와 절벽은 실제 `#` 칸에만 그린다.
- 210 북부의 `(3,17)`, `(20,26)`, `(25,40)` 단차 띠는 실제 보행 칸 위에 있었다. 고정 띠를 제거하고 충돌 경계의 막힌 쪽에 높이와 그림자를 표현한다.
- 봉신 전체가 같은 바닥인 문제를 잔디·낮은 꽃·석재 주통로·생활시설 진입로로 나눴다. 서쪽211↔동쪽210, 유적↔민가, 센터 현관의 경로를 읽을 수 있게 했다. 화단은 걸을 수 있는 낮은 식생이며 신규 장애물은 아니다.
- 211 서부 산기슭·천관산 밝고 짙은 암반·211 동부 숲·210 북부 숲과 절벽을 실제 격자에 대응시켰다. 기존 조우 영역은 덮지 않고 공통 풀밭 렌더러에 맡긴다.

## 중앙 연결 요청

기존 지면 함수는 이미 `src/explore-art.ts`에서 import/호출하므로 추가 연결이 필요 없다. 중앙 소유 파일은 수정하지 않았다.

추가한 `paintCelesticRuinsFacade(c,b)`는 봉신 유적에만 적용되는 전경 함수다. 일반 건물처럼 보이는 유적을 등록된 크기의 이끼 낀 석조 입구로 바꾼다. 중앙은 기존 import에 이 함수를 추가하고 `paintTourBuilding` 시작부(일반 landmark 분기보다 앞)에 다음을 연결해야 한다:

```ts
import { paintSinnohCelesticDetails,paintCelesticRuinsFacade } from './sinnoh-celestic-art';
// inside paintTourBuilding:
if(p.id==='tour_celestic' && paintCelesticRuinsFacade(c,b))return;
```

연결 전에는 지면 보수만 적용되며, 새 전경 함수는 미연결이다. 연결 여부를 구현 완료로 혼동하지 않는다.

## 원작과 프로젝트의 차이

2026-09-13 [Serebii Pokéarth DPPt 봉신마을](https://www.serebii.net/pokearth/sinnoh/4th/celestictown.shtml) 본문을 다시 확인했다. 원작의 동쪽210·서쪽211 및 중앙 유적 관계를 따른다. 현행 프로젝트의 40×40 봉신 크기·남쪽 민가 배치·210/211 축소 통과로와 팔레트는 자체 재구성이다. 원작 타일 배치 복제나 새 본편 사건 적용은 아니다.

## 남은 한계

소스 수정이며 실행·시각 품질·충돌 플레이 검증은 하지 않았다. 넓은 211 십자 통로의 형태와 기존 범용 집/센터 외관은 남는다. 중앙의 통과맵 렌더 등록 수정, 풀밭 등록 수정 및 위 유적 전경 연결이 합쳐져야 최종 화면이 구성된다. 도시 완료로 판정하지 않는다.
