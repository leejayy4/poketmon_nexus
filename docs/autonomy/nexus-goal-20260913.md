# 네 지방 활성 목표의 구현 경계

2026-09-13. 목표는 네 지방의 도시별 여행·포획·성장·전투·사건·귀환 구현이다. 작은 기능이나 문서 완료를 전체 완료로 바꾸지 않는다. QA는 중단 중이다.

## 이번 지역 작업

각 담당은 지방 고유 코드와 지방 인계를 수정한다. 공통 전투·파티 및 공유 JSON 변경은 중앙에 최소 훅/데이터 제안으로 전달한다. 중앙은 실제 결과를 받아 호출·등록·저장 계약의 연결을 읽고 통합한다. 전송 자체는 구현 증거가 아니다. 새 자동화나 별도 작업은 만들지 않았다.

## 전체 완료까지 남은 증명

- 각 도시에서 실제 진입/필수 실내/생태·포획 공급/성장/선택 행동/채택 사건/다음 경유/귀환이 연결됐다는 코드와 플레이 근거.
- 원작 근거와 프로젝트 재구성의 장소별 차이, 외부 코드/자산 재사용 시 출처·라이선스.
- 공통 전투 변경의 실제 동작과 난이도, 저장·재접속·시각/음향 검증. 현재는 모두 QA 재개 전 미판정.
- 위 현재 네 도시의 보수를 넘어 남은 지방별 필수 도시와 본편 장면의 구현. 현재 네 도시만으로 네 지방 완성을 주장하지 않는다.

다음 중앙 회차는 지역 결과와 실제 코드를 대조해 미연결 훅을 처리한다. 문서만 늘리거나 같은 지시를 반복 전송하지 않는다.

## 신오 동료 기록 보수

`field-partner-party.ts`의 기존 선두 교체·PC 교환/입고·경험치 적용 소비 경로에 진행 중 천관산 동료를 추가했다. 실제 객체가 파티에 남으면 슬롯과 진화 후 종을 갱신하고, 파티에서 빠지면 슬롯만 해제한다. 동일 종 대체 개체에 활동을 넘기지 않는다. 완료 기록의 종은 과거 관찰자로 보존한다. 저장 UUID 도입이나 과거에 이미 잘못 연결된 저장 복구는 하지 않았다. 기존 프로젝트 활동의 저장 보수로 신규 원작 사실은 추가하지 않았다. 모든 QA 미실행.

## 봉신 필수 시설 소비 연결

`tour_celestic_center`의 실제 PC 오브젝트는 `sinnoh-celestic-route.ts`에 `tourPC`로, 그림은 `sinnoh-celestic-center-art.ts`에 같은 이벤트로 등록되어 있다. 기존 공통 메뉴가 `tourExhibit1`만 소비하여 설명 대사로 빠지던 부분을 `journey-services.ts`에서 봉신 전용 별칭으로 연결했다. 기존 PC 편성/입고/교환과 동료 추적을 그대로 사용한다. 원작 지리나 새 기능 도입이 아닌 기존 시설 연결 결함 수정이다. 플레이·입출고·저장 QA는 중단으로 미실행.
