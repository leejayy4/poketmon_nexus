# 봉신 실내 생활공간 보수 — 2026-09-13

## 변경

`src/sinnoh-celestic-interior-art.ts`에 봉신 민가 두 곳의 전용 바닥·가구 painter를 구현하고 `src/explore-interior-art.ts`의 기존 실내 바닥 및 가구 렌더 함수에 직접 연결했다.

- 노부부 상점: 카운터로 이어지는 중앙 통로, 목재 측면 바닥, 물품을 살펴보는 자리 구분. 기존 산길 보급 선반은 몬스터볼·약병 진열대로, 주문표는 주문 장부와 필기구를 놓은 낮은 책상으로 표현한다. 판매는 기존 카운터에서만 처리한다.
- 전승가옥: 기존 기록·지도 앞의 열람 돗자리, 문으로 이어지는 중앙 마루. 가족 기록은 여러 칸의 서가, 천관산 옛 지도는 산줄기와 길을 표시한 펼친 지도 책상, 동료 휴게는 세 개의 낮은 방석으로 표현한다.
- 실제 호출은 `paintTourInterior`의 확대 실내 바닥 뒤와 `paintTourFurnishing`의 기본 가구 처리 앞에 연결했다. 해당 MapId 또는 기존 furnishing event만 선택하므로 다른 지방 가구는 기본 경로를 유지한다.

## 보존 / 원작 차이

상점·전승가옥 24×20과 모든 보행 칸·벽·가구 footprint·NPC·조사 event·문/warp를 보존했다. 이번 작업은 동선을 재배치한 것이 아니라 기존 동선과 활동의 용도를 시각적으로 구분한 것이다. 원작 신규 사실이나 본편 사건을 채택하지 않은 프로젝트 실내 재구성이다. 기존 원작 장소 근거는 REFERENCE_RESEARCH의 봉신 생활시설 절을 따른다.

## 검증 / 남은 문제 / 다음 시작점
