- 34번도의 서식 근거를 [HGSS 34번도로](https://www.serebii.net/pokearth/johto/route34.shtml)에서 확인했다. 꼬렛·슬리프·캐이시·메타몽 중 현재 플레이에 쓸 꼬렛/슬리프부터 연결한다. J13 목장 권역을 34번으로 오인하지 않는다.
- `scripts/design/runtime-local-pools.json`이 지리/출처와 프로젝트 레벨22~24·비중40/60을 기록하는 원본이다. `export-runtime-pokemon.py`는 이 파일을 읽고 해시를 자산 출처 명세에 포함한다. 기존 생성 JSON을 직접 편집하지 않았다. 슬리프 앞/뒤 PNG2개, 공통 종·학습·포획/도감 데이터 연결.
- `goldenrod-route.ts` 풀밭은 (10,16)3×2, (18,23)4×2. 첫 풀밭 접근 공터를 확장했으며 기존 큰길/강가 순환길은 조우 없이 통과한다. `goldenrod-art.ts`는 공통 DS 긴풀 렌더를 쓴다. 기존 타일을 새 장애물로 막지 않는다.
- `goldenrod-radio.ts`: 길 안내·실제 조우표·센터/라디오 목적지, 원산지별 파티/박스 관찰 기록, 시장 주민의 부상·도구 상태별 센터/상점 안내, 청취자의 방송 소개 연결. 돈·보상·필수 퀘스트·새 저장 필드 추가 없음.
- 최소 확인: 생성 성공, 타입 검사, 슬리프24 데이터에서 HP86/염동력·박치기/met 확인, PNG 파일과 diff. 도시 QA·자연 포획·저장 복원·그림/소리 직접 확인은 아직 수행하지 않았다.
- 다음 작업: 역과 생활/주거 구역·필드 포켓몬의 지역 배치 및 라디오/다음 출구 연출 통합. 자연 포획·회복·PC·라디오 기록·저장 왕복은 금빛의 필수 구현을 모두 마친 뒤 도시 QA에 모은다. 슬리퍼 진화·캐이시/메타몽·수면·시간 조우는 미구현이며 현행 기능으로 안내하지 않는다.
- 이전 태초 저장·다른 담당의 도시 인계 보존. 새 QA 저장을 만들지 않았고 재개 위치는 아직 코드 기준 금빛/34번도로다.

아래 1단계의 ‘조우 없음’과 다음 작업은 당시 이력이며 위 2단계가 우선한다.

## 목표와 경계

사용자의 `성도지방 continue`에 따른 이 대화의 담당 도시는 금빛시티다. 다른 작업의 관동 홍련·신오·하나 파일과 인계는 보존한다. 금빛 외부·기존 필수 실내·노랑 연결 입구·남쪽 34번도로·너도밤나무숲 북쪽 문턱까지 담당하며 고동과 숲 전체, 35~37번 공통 분기의 완성을 동시에 요구하지 않는다.

도시 완료 조건: (1) 역/상업/주거/라디오 구역 및 담당 연결 동선 (2) 현지 포켓몬·조우·육성과 주민/시설 활동 (3) 기존 DP풍 자산·표지/안내·전투/생활 연출 연결 (4) 앞 항목 구현 뒤 도시 플레이·취소·귀환·저장·시각/음향 QA. 세부 하위 기능 완료 때 QA를 반복하지 않는다.

## 변경

- `src/goldenrod-route.ts`: 독립 34번도로 32×42. 기존 금빛/숲 출구와 되돌아갈 좌표를 보존한다. 도로 북(14,1)→금빛(14,33), 남(14,40)→숲(10,3); 도로 진입은 북(14,3), 남(14,38). 큰길·순환 샛길·관찰 자리·쉼터·여행자·표지. 기존 일회 아이템을 복제하지 않고 새 보상/잠금 없음.
- `src/goldenrod-art.ts`: 기존 DS 바닥·흙길·완전한 나무와 강변·의자·표지 그림. `explore-art.ts`의 도로 배경 선택에 연결. 금빛 라디오 건물에 안테나·간판 추가.
- `src/explore-world.ts`: 신규 도로를 지도·길안내·방문 기록이 참조하는 등록부에 연결. 독립 제작한 도로 표지는 공통 좌우 표지로 덮어쓰지 않는다.
- `src/explore-expansion.ts`: 금빛의 역 쪽 포장 공간·라디오 앞마당·상업 골목 바닥 확장. 기존 건물·충돌·NPC 위치 보존. 다른 담당의 홍련 계획 분기는 유지.
- `src/goldenrod-radio.ts`, `journey-services.ts`: 기존 라디오 1층 조정석 또는 안내원 → 파티 선택(3개씩 페이지) → 원고/주제 선택 → 대화형 녹음 체험 → 복귀/34번 길안내. 실제 음성 입력/출력은 없다. 파티 없음·취소·세션/파티 변경 가드, 보상/저장 변이 없음.

## 최소 확인

`npx.cmd tsc --noEmit` 통과. 실제 모듈 로드로 신규 맵 생성·양쪽 워프·안전 도착 좌표·표지 2개 확인. 문서/코드 공백 검사. 도시 구현이 끝나지 않아 전체 테스트·빌드·브라우저·소리 청취를 실행하지 않았다. 기존 테스트 수·QA 성공을 이번 구현의 검증 근거로 재사용하지 않는다.

## 남은 구현과 정확한 재개

- 금빛의 생활 포켓몬·주민 배치와 장소별 실제 역할, 지역 조우·기술/육성 연결은 미완료다. 34번은 실제 이동 가능한 지도지만 현재 야생 조우는 없다. 방사형 도시 기본 동선을 완전히 재설계한 것은 아니다.
- 다음 하위 작업은 금빛 34번도로에 대응하는 확정 조우 원자료를 검토하고 도시 보급·방송·새 동료 활용을 연결하는 지역 생태 구현이다. 다른 지역 풀을 임의 대입하지 않는다. 역·상업 생활의 미완료도 동일 도시 목표로 이어간다.
- 사용자 실제 저장과 기존 여행 QA는 조작하지 않았다. 이번 금빛 직접 QA 위치는 없다. 구현 재개 지점은 금빛 남쪽(14,33) 또는 라디오 1층 조정석 앞이며, 도시 QA 시 새 고유 사본으로 준비한다. 관동 태초 저장은 별도 진행으로 보존한다.
- 다음 QA 시작 조건은 위 금빛 도시의 필수 구현 전체 완료다. 3회차·기능 완료 규칙을 재도입하지 않는다.
