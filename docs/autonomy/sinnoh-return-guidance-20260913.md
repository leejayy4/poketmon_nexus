- 검증: 세 지침·최신 인계·소스와 실제 목적지 이벤트 등록을 읽고 구현. QA 중단으로 테스트·빌드·브라우저·저장·시청각 검증 미실행. 구현·미검증이며 도시 완료가 아니다.
