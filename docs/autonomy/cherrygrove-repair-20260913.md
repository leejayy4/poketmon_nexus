# 무궁시티 기존 지도 보수

- 후속 충돌 정정: 북문 울타리 전체를 막힌 y=1 행 안으로 제한했다. 서쪽 물·모래·돌담은 `walkable === '#'`인 해안 칸 안에서만 그려 보행 산책로로 돌담이 침범하지 않게 했다. 추가 QA는 실행하지 않았다.

- 원인:44×40 크기만 확보하고 넓은 직사각형 길과 남쪽 수면 한 줄을 배치했다. 서쪽 바다·꽃의 도시라는 장소 구성이 드러나지 않았다. 실내 부모도 Place 대신 문자열로 등록했다.
- 변경: `src/johto-cherrygrove.ts`에서 서쪽 수면→굽은 해안→남서 만, 센터 꽃울타리·상점 앞 꽃밭·주민 공동 화단·방풍림을 충돌 지형으로 배치했다. 기존 건물 네 곳과 문·동쪽29번 출구를 보존하고 관찰대를 서쪽 해안으로 옮겼다. 실내 부모 등록을 Place로 수정했다.
- 전용 표현: `src/johto-cherrygrove-art.ts`의 `paintCherrygroveGround(c,map)`가 포장길·단차 해안/파도·개별 꽃잎/화단 경계·북문 목재 울타리·문 앞 계단을 그린다. 공통 지형/feature 뒤, 건물과 조사물 앞에서 호출한다. 중앙이 소유한 explore-art.ts는 수정하지 않았다.
- 근거:2026-09-13 [Bulbapedia Cherrygrove City](https://bulbapedia.bulbagarden.net/wiki/Cherrygrove_City), HGSS 항목. 원작은 꽃·바닷바람, 서쪽 해상 섬, 동쪽29·북쪽30번도로가 있다. 프로젝트는 기존 문 좌표를 보존한44×40 재구성이며 원작 타일 복제가 아니다. 원작 상점/센터 상대 위치, 해상 섬·파도타기·안내 할아버지 신발 보상은 이번에 재현하지 않았다.
- 한계: 전용 painter의 공통 렌더 연결은 중앙 담당에게 인계. 새 도시·맵·크기 변경 없음. 테스트·빌드·브라우저·저장·시청각 QA는 전부 실행하지 않았으며 실제 화면 완성으로 판정하지 않는다.
