# 스토리 기준 Goal 등록과 문서 정리 · 2026-09-20

사용자 지시 `싹 다 문서에 반영하고 문서들 정리` · `스토리를 기준으로 완성되는 포켓몬 넥서스 구현을 잡아라`에 따른 회차다. **문서 작업 회차이며 런타임 구현·도시 완료·QA 재개가 아니다.**

## 0. 범위와 한계

- 수행: 장별 실행 플래그 분류 조회, 서사 설계 문서 전문 검토, 참고 자료 활용 실측 확인, 기존 문서 구조 확인, 문서 신규 2건·개정 5건, **대상 검사 1건**.
- 미수행: 전체 테스트 묶음, QA 게이트 `npm.cmd run build`, 브라우저 플레이, 보행·워프·조우·전투 실행, 시각·음향, 저장 재접속.
- 런타임 코드는 변경하지 않았다. 커밋·푸시·의존성 추가도 하지 않았다.

## 1. 장별 구현 현황 조회 — 이번 회차의 핵심 발견

`src/*.ts`의 `nexus*` 접두 실행 플래그 130종을 장별로 분류했다.

| 장 | 플래그 | 상태 |
| --- | ---: | --- |
| **CH00~02 신오 출발 (3초 오차 · 관동행 선택)** | **0** | **미구현** |
| CH03 관동 (실프 · 홍련 · 뮤츠) | 16 | 구현됨 |
| CH04~05 성도 (분노의호수 · 황토 · 금빛 · 인주 · 모라) | 44 | 구현됨 |
| CH06 하나 전반 (구름 · 뇌문 · 무쇠 · 궐수) | 20 | 조사 단계까지만 |
| **CH07 하나 후반 (용나선 · 고대성 · 큐레무)** | **0** | **미구현** |
| **CH08 신오 귀환 (3초 원본 비교)** | **0** | **미구현** |
| **CH09 창기둥 · 깨어진세계** | **0** | **미구현** |
| CH10 후일담 | 0 | 미구현 |
| (공통) 도로별 실제 동료 실전·귀환 | 약 50 | 구현됨 |

**판정: 구현이 3장부터 지어졌다.** 전체 서사의 척추인 3초 오차가 게임에 존재하지 않아, 플레이어는 여행을 시작한 이유를 모르는 채 관동에서 장비 납품 기록을 듣는다. 서진(최종 주적) 관련 플래그 0건이며 적이 설비와 서류로만 존재한다. 전설 12종 중 구현은 뮤츠 1종이다.

## 2. 장별 필요 시스템 역산 — 무엇이 막고 있는가

| 장 | 선행 시스템 | 새 맵 |
| --- | --- | :---: |
| **CH00~02** | **없음. 현재 엔진으로 전부 가능** | **0** |
| **CH08** | **없음. 플래그 5개** | **0** |
| CH04~05 소용돌이섬 | 파도타기 (제안 C10) | 0 |
| **CH09 최종전** | **레벨 상한 25 → 36+ (제안 C9)** | 0 |
| CH06~07 | 없음 (작업량 문제) | 자이언트홀만 필요 |

**서사의 첫 단추(CH00~02)와 회수 지점(CH08)이 둘 다 새 시스템·새 맵 없이 지금 만들 수 있는 상태로 비어 있다.** 반면 CH09는 설계 기준점 Lv.61~68과 현재 상한 25의 격차로 구조적으로 막혀 있다.

## 3. 서사 설계 검토 — 강점과 공백

`NEXUS_STORY_MASTER.md` 315줄 전문을 읽고 평가했다.

**강점(유지):** 네 지방을 `완벽한 세계를 위해 지금 살아가는 이들의 선택을 지워도 되는가`라는 질문 하나로 묶은 것. 금지 목록(책임 전가·몰래 완성·연설 면책·강요된 용서·아르세우스 만능화·시간 되돌리기)이 팬 서사의 함정을 정확히 회피한 것. 이안의 `보고서가 틀린 게 아니라, 내가 듣지 않은 말이 있었어`와 주민이 즉시 용서하지 않는 처리 — 이미 `nexusEcruteakIanAdmitted`·`nexusEcruteakResidentsDemanded`로 구현까지 됐다. 16절이 전설 12종에 각자의 행동 이유를 준 것.

**공백과 개선안:** [NEXUS_STORY_MASTER 제19절](../NEXUS_STORY_MASTER.md)에 S1~S6으로 기록했다.

| # | 내용 | 처리 |
| ---: | --- | --- |
| S1 | 3초를 읽는 정보가 아니라 **재는 행동**으로. 네 지방 관측 → CH08에서 자기 저장이 증거 | **채택** (15·16절의 메커닉화) |
| S2 | 서진을 CH01에서 한 번, **선의로** 만난다 | **채택** (설계 공백) |
| S3 | 세 성수를 다른 동사로 (라이코=추적 / 앤테이=버티기 / 스이쿤=조사) | **변경 제안 — 미채택** |
| S4 | 지방마다 관장 1명을 대표 사건 공동 주역으로 | **채택** (3절 구체화) |
| S5 | 유진을 끝까지 수렴시키지 않는다 | **변경 제안 — 미채택** |
| S6 | 가족 연락 4회 · 도윤 중간 약속 · 따라큐 장면화 · PG의 조용한 축 | **채택** |

S3·S5는 채택된 4절·12절의 변경을 요구하므로 **사용자 결정 전까지 기존 설계를 우선한다.** [루트 AGENTS](../../AGENTS.md)의 `구현 지시서의 우선 적용을 확정 계약의 임의 변경 권한으로 해석하지 않는다`를 따른다.

## 5. 다른 작업자 변경의 보존과 확인

이번 회차 도중 다른 작업자가 `docs/NEXUS_GOAL.md`를 작성하고 **C3 모듈 초기화 순환 해소**를 완료로 기록했다(`src/trainer-flags.ts` 신설로 `mahogany-transmitter → road-trainers → maps` 간선을 끊는 방식).

- **되돌리지 않았다.** 그 문서를 Goal의 단일 대장으로 두고 이쪽 로드맵을 종속시켰다.
- **대상 검사로 확인했다.** `npx tsx --test tests/collision.test.ts`가 더 이상 `Cannot access 'TOUR_MAPS' before initialization`으로 죽지 않고 **로드되어 실행된다.** 남은 출력은 `tour_lacunosa: disconnected floor at 2,3` 같은 맵 내용 단언 실패이며, 이는 해당 문서가 `C4 되살아난 검사의 기존 실패 정리 · 진행 중`으로 분류한 항목과 일치한다.
- 이 확인은 [상세 AGENTS](../AGENTS.md#검증과-도시-완료)가 허용하는 개발 중 최소 확인 범위의 **단일 대상 검사**다. 전체 묶음·빌드·브라우저는 중단을 유지했다.

## 6. 남은 문제

1. CH00~02·CH07·CH08~09가 실행 플래그 0건이다. 본편이 이어지지 않는다.
2. 서진과 팀 아크가 런타임에 존재하지 않는다.
3. CH09가 레벨 상한 25로 구조적으로 막혀 있다.
4. 제안 C8~C12가 아직 Goal 대장에 채택되지 않았다.
5. S3·S5는 사용자 결정 대기다.
6. C4(되살아난 검사의 기존 실패) 분류가 진행 중이다.

## 7. 다음 작업

[스토리 기준 로드맵 제7절](../STORY_AXIS_ROADMAP.md)의 Phase 1이다. C3가 완료됐으므로 남은 것은 C4 분류와 CH00~02 구현이며, 새 시스템·새 맵이 필요 없다.

1. C4 — 로드 가능해진 검사의 실패를 낡은 기대값 / 실제 회귀로 **분류만** 한다.
2. CH01 3초 관측 이벤트 (축복·영원의 기존 도시).
3. CH01 서진 선의 조우.
4. CH02 관동행 선택 연결. 기존 `researchDelivered`·조사선 계약 보존.

이 작업은 [NEXUS_GOAL](../NEXUS_GOAL.md)의 현재 도시(신오 무쇠시티)와 병행 가능한 별도 축이며 도시 작업을 중단시키지 않는다.
