2026-09-12 · **50개 문서를 이동했고 삭제한 파일은 없다.** 사용자 결정 전에는 삭제하지 않는다. 현재 작업 지시가 아닌 과거 검토/회차 기록이다. 링크 위치만 조정하고 당시 구현·실패·QA 결과는 보존했다.

## 복원·삭제 절차

[move-manifest.json](move-manifest.json)에 원래/현재 절대 경로와 저장소 상대 경로를 보존했다. 복원은 해당 파일을 원래 위치로 옮기고 현재 Markdown 링크를 반대로 갱신한다. 원래 위치에 새 파일이 생겼다면 덮어쓰지 말고 두 내용을 비교한다. 위치 변경 과정에서 링크를 재배치했으므로 파일만 되돌리고 링크를 방치하지 않는다.

삭제는 사용자가 지정한 파일만 별도 작업으로 진행한다. 고유 검증 근거·출처·현재 참조 유무를 먼저 읽고 필요한 내용을 보존한 뒤 삭제한다. 이 목록과 과거 Git의 삭제 표시(이동의 원본 경로)는 실제 폐기 승인이 아니다. 서버·자동화·QA를 실행하는 절차가 아니다.
