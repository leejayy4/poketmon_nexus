# 첫 배지 Vertical Slice 제작·수용 기준

2026-09-22 재정립. **본편 1~2장의 여행과 공통 제작 방식을 증명하는 첫 제작 묶음**이다. 아래 목표는 제작 계획이며 이미 구현·검증됐다는 선언이 아니다.

서사는 [메인 확정 기준](story/NEXUS_MAIN_STORY_CANON.md)·[본편 1~2장](story/NEXUS_STORY_COMPLETE.md), 실행 상태는 [STORY](STORY.md), 전체 순서는 [로드맵](STORY_AXIS_ROADMAP.md)을 따른다. BW·BW2풍이 현재 표현 목표다.

## 1. 범위와 끝나는 지점

목표 여행은 **새 게임 → 가족과 첫 동료 → 떡잎마을 출발 → 201번도로 → 진실호수 왕복 → 잔모래마을 → 202번도로 → 축복시티의 세 초 징후 → 203번도로 → 무쇠게이트 → 무쇠시티·탄갱 → 첫 체육관 → 유진과 첫 배지의 밤 → 귀환·저장/불러오기 → 꽃향기 방향 안내**다.

진실호수는 초기 생태·길 찾기 경험이다. 전설 획득이나 주인공 접점 노출을 앞당기는 장면이 아니다. 자연 진행 수용에서 방문하되 방문·포획을 체육관 통행료로 만들지 않는다.

본편 2장의 뒤쪽 서진 구호 만남은 꽃향기 방향 다음 제작 묶음으로 잇는다. 따라서 이 slice 수용은 **본편 2장 전체 완료나 신오 완료가 아니다.** 첫 승리의 기쁨과 다음 여행 동기가 성립하는 지점에서 닫는다.

한 번에 전 지방·전체 도감·모든 전투 기능을 만들지 않는다. 여기서 실제 사용하는 종·기술·도구·NPC·장면·맵·저장이 같은 제작 경로로 끝까지 이어져야 한다.

## 4. 실행 순서와 작은 완료 단위

1. **연결·저장 바닥:** 최종 지도 조립에서 호수 분기와 잔모래 실내 문을 보존하고, 신규종 수령·배지·위치 이행의 저장 계약을 명세한다. 이동 불가·저장 거부 상태 위에 대사를 더하지 않는다.
2. **새 게임·출발 묶음:** 가족·선택한 이름/외형·첫 동료·유진·도윤을 연결한다. 가족 엽서는 성적 보고나 의무 수집 잠금이 아니다.
3. **첫 두 도로·호수·잔모래:** 발견→포획→현재 동료 실전→센터·도구 준비→다음 길·귀환을 만든다. 각 장소의 행동은 서로 달라야 한다.
4. **축복·203·게이트:** 시계 징후를 직접 관찰하고 원인은 미정으로 남긴다. 도로·동굴의 안전길과 선택 탐험, 도시 안내를 잇는다.
5. **무쇠 도시 묶음:** 진입 구간·탄갱 강석·동료 생태·실내·준비·관장전·실제 승리·유진 축하·다음 길·귀환을 완성한다.
6. **현재 저장과 신규 저장 수용:** 재개 허가 뒤 대표도시 QA와 전체 slice 자연 진행을 순서대로 확인한다. 결함을 고친 항목만 다시 확인한다.

기존 첫걸음·회복·PC·기술 학습·탄차·무쇠 동료 활동을 모두 새로 작성하지 않는다. 필요한 소비 연결·중복 처리·최종 표현만 보수하고, 현재 의미를 보존할 수 없는 부분에 한해 이행한다.

## 5. 플레이어가 경험해야 할 것

- **출발 이유:** 챔피언 방송과 가족·또래 관계로 첫 여행의 기대를 이해한다. 세계를 구할 의무부터 받지 않는다.
- **발견:** 풀밭을 피할 길과 탐험할 길을 구분하고, 새 포켓몬을 만나 직접 포획할 수 있다.
- **성장:** 잡은 동료를 전투에 쓰고 기술·교체·회복 선택이 첫 관장전 준비에 영향을 준다.
- **생활:** 센터·상점·PC·주민·탄갱에 들를 실제 이유가 있으며 모든 대화를 의무로 완료하지 않아도 진행된다.
- **NEXUS 징후:** 축복 초침과 흐르는 분수의 차이를 본다. 도시 전체가 멈췄다거나 주인공에게 시간 능력이 생겼다고 기록하지 않는다.
- **승리와 실패:** 실제 강석전 승리로 배지를 받고, 패배하면 안전한 회복·재도전으로 이어진다. 강제 승리/패배 컷신을 넣지 않는다.
- **관계와 귀환:** 유진과 첫 성취를 나누고 현재 동료·배지·장면 결과가 귀환·재접속 뒤에도 남는다.

## 6. 장면·동료·저장 안전 조건

[이야기 실행 계약](STORY.md)의 상태 분리를 따른다. 원고 장 번호를 저장 키로 기계 치환하지 않는다.

스타팅이 진화하거나 PC에 있어도 현재 건강한 동료로 필요한 장면을 진행할 수 있어야 한다. 같은 종의 다른 개체를 이전 당사자로 오인하지 않도록 추적한다.

첫 배지 축하 장면은 배지 보유가 근거이며 원고에 있다고 자동 지급하지 않는다. 취소·다음 방문·동료 기절·파티 교체·재접속에도 마지막 확정 단계부터 안전하게 이어진다.

선택 탄차·광맥 관찰·주민 부탁·특정 현지 포획·트레이너 승리는 첫 배지나 출구의 새 필수 조건이 아니다. 무료 보급 종료·상점 이용 전환은 사용자에게 이해되게 안내한다.

접점 노출은 본편 3장, 서진 첫 구호 만남은 첫 배지 뒤 꽃향기 방향이다. 이 slice를 대표성 있게 보이게 하려고 전설·실종의 전모·회상·최종장 장치를 앞당기지 않는다.

## 7. 두 개의 수용 게이트

**현재는 QA 중단이다.** 아래는 명시적 재개 후 시행할 완료 기준이며 이번 문서 작업으로 실행하지 않는다. 재개 전에는 ‘구현 중/코드 반영·미검증’으로 남긴다.

| 게이트 | 시작 조건 | 확인 범위 | 통과가 뜻하는 것 |
| --- | --- | --- | --- |
| 대표도시: 무쇠 | 무쇠 외부·계획된 실내·탄갱·담당 진입/출발 구간·사건·생활·표현 구현 완료 | 직전 축복 거점→203·게이트→무쇠→탄갱·시설·준비·관장전·유진→다음 출구/귀환. 취소·패배·저장·시각·음향 포함 | 해당 도시 묶음 수용. 새 게임 도입·다른 도시·전체 slice 완료를 뜻하지 않음 |
| 전체 Vertical Slice | 도입부터 첫 배지 뒤 귀환까지 모든 묶음과 대표도시 결함 수정 완료 | 신규 세 스타팅 각각 새 게임부터 목표 여정을 자연 진행. 준비 파일 주입 없이 포획·성장·구매·회복·승리·귀환·저장/재접속을 확인 | 현행 신규종·서사·기술 기반의 첫 배지 여정 수용. 본편 2장 전체·신오·장기 Goal 완료 아님 |

구형 저장 이행은 실제 저장 사본으로 별도 확인하고 자연 진행 기록과 섞지 않는다. 준비 저장으로 취소·패배·PC·보상 중복 경계를 확인한 결과도 자연 성장 완주로 표기하지 않는다.

수용 기록에는 시작 조건, 사용 종·실제 기술/레벨, 선택 동료, 이동·반복 육성 부담, 소비 도구, 실패와 재개, 저장 결과, 시각/음향 확인 여부를 남긴다. 문서 길이·맵 수·자동 검사 개수로 대체하지 않는다.

## 8. 이번 계획 이후 인계

현재 코드·미검증 범위·구현 파일은 [STORY](STORY.md)와 현재 상태 문서에, 다음 작은 작업은 [로드맵](STORY_AXIS_ROADMAP.md)에 한 번만 기록한다. slice 계획을 도시별 오래된 작업 배정과 중복 실행하지 않는다.

과거 첫 배지 플레이와 스타팅별 결과는 [재편 전 원문](archive/2026-09-22-rebaseline/FIRST_BADGE_SLICE.md)에 보존한다. 그 기록은 당시 기존종·지도·전투 규칙의 증거이며 신규 스타팅과 현재 전체 경로의 수용을 보장하지 않는다.
