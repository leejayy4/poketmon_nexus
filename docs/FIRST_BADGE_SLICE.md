# 첫 배지 구간 기준

기준일: 2026-09-08 · 대상: 새잎마을 → 서쪽길 → 축복시티 → 암반굴 → 무쇠시티 → 첫 배지

이 문서는 첫 배지까지의 구간을 점검하기 위한 짧은 기준이다. 현재 코드에 있는 사실, 사용자가 확정한 방향, 이번 후보의 진행 상태와 최종 검증을 구분한다. 탄갱 사건·라이벌·새 본편 사건을 이 구간에 임의로 추가하지 않는다.

## 사용자 확정 기준

- 필드와 화면은 Nintendo DS 다이아몬드·펄·플라티나풍을 기준으로 한다. 이후 포켓몬 시리즈의 콘텐츠 참고는 가능하다.
- 현재 마을·도시의 크기에 고정하지 않는다. 여행 경험에 필요하면 구역·도로·동굴·실내를 확장하거나 재배치할 수 있다. 첫 배지 구간의 완성을 우선하며, 다른 지방의 지도 수를 늘리는 것을 진척 기준으로 삼지 않는다.
- 여행 루프는 출발 준비 → 새 동료를 만남 → 성장·기술 준비 → 회복·도구 보충 → 기존 주민 활동 → 암반굴 통과 → 체육관 도전이다.
- 탄갱 사건과 라이벌은 세부 설정이 확정될 때까지 제외한다.
- 첫 배지 구간을 정리한 뒤 영원숲·영원시티로 이어가고, 장기 순서는 신오 출발 → 관동 → 성도 → 하나 → 신오 귀환 이후의 이야기로 확장한다.

## 구간을 완성하는 작업 순서

작업 단위는 마을·도로·그래픽 파일 종류가 아니라 **출발 준비부터 다음 도시의 체육관 승리와 다음 여행까지**다. 아래는 사용자 확정 개발 방향이며 구현 완료 선언이 아니다.

| 순서 | 함께 완성할 내용 | 플레이에서 확인할 결과 |
| --- | --- | --- |
| 1. 여행 동선 | 출발 마을·서쪽길·축복·암반굴·무쇠의 입구와 출구, 안전 통과길과 선택 샛길 | 길을 이해하고 이동하며 탐험할 길을 선택할 수 있다 |
| 2. 마을과 도시 경험 | 시설 실내·상점·회복·주민의 기존 활동, 고층 시설의 층간 이동 | 건물에 들어가고 사람에게 말 걸 이유가 있으며 준비가 다음 여행에 도움이 된다 |
| 3. 발견과 성장 | 지역별 동료·드문 종·트레이너·도구·기술 학습·파티 구성 | 도로와 동굴에서 얻은 동료와 성장이 다음 관장전에 쓰인다 |
| 4. 전투와 연출 | 구간에서 실제 사용하는 기술, 공격 준비→이동/접촉→피격→HP 감소→효과 설명 | 선택한 기술의 역할과 결과를 화면에서 이해할 수 있다 |
| 5. 배지와 다음 여행 | 체육관 도전·보상 사용·기존 주민 반응·다음 목적지 | 배지가 여행의 성과로 느껴지고 다음 구간으로 이어진다 |
| 6. 전체 플레이 조정 | 새 게임부터 배지까지 이동·대화·전투·회복·저장 재접속 | 반복과 난이도를 실제 흐름에서 확인하고 확인된 문제를 수정한다 |

장소의 그림·재질·실내 구성과 해당 장소의 소리, 구간에서 쓰는 기술 연출은 각 작업에 함께 포함한다. 기술 그래픽 전체를 마지막 단계로 미루지 않는다. 규모는 고정하지 않지만 빈 공간이나 반복 시설만 늘려 완성도로 계산하지 않는다.

## 구간 완료 판단과 현재 남은 검증

- 개별 기능 테스트·fixture 플레이·맵 연결 검사는 부분 검증이다. 이를 구간 전체 완료로 올리지 않는다.
- 새 게임부터 첫 배지까지 직접 플레이하며 시설 방문 이유, 안전길/샛길 선택, 동료 발견, 속성 기술 학습·사용, 회복·구매, 관장전·보상·다음 목적지를 함께 확인한다. 선택 콘텐츠를 필수 조건으로 바꾸지는 않는다.
- 플레이 기록에는 스타팅·포획 동료·레벨과 기술·전투 및 이동 부담·막힌 지점·수정 후 재확인 결과를 남긴다. 초반 세 스타팅의 준비 방법과 관장전 난이도를 구분해 검토한다.
- lead-0004의 꼬부기 첫 배지 플레이 이력은 아래에 유지한다. 이후 lead-0005~0012의 개별 기능 검증을 파이리·이상해씨 자연 성장 완주로 간주하지 않는다. 현재 구간의 최종 수용은 미완료다.
- 구간 검증이 남아 있으면 다음 회차도 그 검증과 발견된 문제를 이어간다. 안내 문구·아이콘 같은 작은 보완만 새 목표로 반복하며 전체 플레이를 계속 미루지 않는다. 저장 손상·진행 막힘은 즉시 우선한다.
- 첫 배지 구간을 만족스럽게 정리한 뒤 영원숲→영원시티→다음 배지에 같은 기준을 적용한다. 이후 신오→관동→성도→하나 순서로 스토리에 맞춰 확장한다. 미확정 사건은 별도 결정 후 구현한다.

## 코드와 구간 방향의 구분

- 현재 주민 활동 두 개는 선택 활동이다. 축복시티 활동은 서로 다른 소유 종 두 가지를 요구하고 몬스터볼을 지급한다. 무쇠시티 활동은 두 마리 이상·전원 회복·Lv.8 이상을 확인하고 상처약을 지급한다. 둘 다 체육관 도전 조건이나 본편 퀘스트 플래그가 아니다.
- 현재 시설은 센터 회복·복귀점 등록, 상점 구매, PC 보관·인출·도감 확인을 제공한다. 무료 보급은 첫 배지 전까지이며 배지 후에는 회복과 상점 안내로 바뀐다.
- 현재 모험 목표 안내는 출발 완료 뒤 첫 미획득 체육관인 무쇠체육관을 바로 목표로 선택한다. 축복·암반굴·무쇠의 주민 활동과 준비 과정은 코드상 선택 사항으로 남아 있다.
- 사용자 확정 방향은 위의 동료·성장·회복·시설·주민 활동이 첫 배지 도전의 여행 경험으로 자연스럽게 연결되는 상태다. 이 문서만으로 새로운 필수 플래그, 보상, 사건, 지역 잠금을 확정하지 않는다.

## lead-0004 구현 및 검증

- 축복·무쇠 안내원에게 센터·상점·주민 부탁·다음 길을 선택하면 실제 통합 맵의 도보 경로가 표시된다. 선택 활동이며 순간이동이나 필수 진행 조건을 추가하지 않는다.
- 콜배지 이후 안내는 기존 영원숲으로 이어지고, 이후 배지도 얻으면 현재 모험 목표를 따른다. 관측 자료 전달 분기는 유지한다.
- 불꽃세례·물대포·덩굴채찍은 준비 → 이동/접촉 → 피격 → HP 감소 순서로 표시한다. 실제 전투 계산과 저장 형식은 유지한다.
- 자동 테스트 411/411, `npm.cmd run build` 통과.
- 고유 QA 새 저장에서 꼬부기 수령 → 서쪽길 전투·찌르꼬 포획 → 거품 학습 → 축복 주민 보상·구매·회복 → 암반굴 탐험 → 무쇠 주민 보상·회복 → 강석 3마리 승리와 콜배지까지 직접 진행했다.
- 저장·재접속 후 꼬부기 Lv.10, 찌르꼬 Lv.3, 콜배지, 스텔스록 TM, 1900원과 주민 보상 플래그 유지를 확인했다.
- 세 기술 연출은 별도 QA 저장의 파일 가져오기 기능으로 준비한 전투에서도 확인했다. 새 게임 진행 저장에는 파일을 가져오지 않았다.
- 초반 개발 중 HMR로 저장 전 전투가 중단된 구간이 있어 전체가 한 번도 재로딩 없는 연속 실행이었다고 주장하지 않는다.
- 다른 스타팅의 전 구간 난이도, 전체 지방 완성도는 미검증이다. 탄갱 사건·라이벌 등 미정 이야기는 추가하지 않았다.
