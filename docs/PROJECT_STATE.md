**기준: 2026-09-22 초기 이벤트·신규 게임 도입 통합 후 코드·호출 경로 정적 검토.** 테스트·타입검사·빌드·브라우저·저장·시청각 QA는 실행하지 않았다. 아래 코드 존재·연결은 실제 플레이 통과와 다르다. 현재 작업 트리에는 이번 작업 이전의 미커밋·미추적 구현이 있다.

- 제품·기술 방향: [NEXUS_GOAL](NEXUS_GOAL.md)의 HYBRID. 여러 지방의 새 지도를 동시에 늘리는 이전 운영을 후속 계획의 기본으로 삼지 않는다.

## 이번 시작 구간의 코드 연결

- [새 게임](../src/nexus-opening.ts)·[이름 입력](../src/nexus-profile.ts): 이름/파랑·산호 옷 → 난천 경기 중계 → 엄마의 빈 엽서 네 장과 반응 선택 → 은솔/하린 → 세 동료 선택 → 실제 연구소 출구 → 기존 집 앞 소개/산책 → 도윤의 일회성 출발 보급. 엽서는 별도 도입 플래그로 기록하며 배지용 `keyItems`에는 넣지 않는다. 취소는 수령/응답을 기록하지 않는다.
- [세 동료](../src/nexus-starters.ts): 900001 새록(풀·사슴), 900002 잿울(불꽃·늑대), 900003 포말이(물·물범). 이름·타입·수치·외형은 **제작용 잠정안**이다. 생성 입력·런타임·Lv5 수령·학습/PP·HP 성장·선택창/도감·앞/뒤 SVG 경로를 연결했다. 최종 디자인·진화·BW/BW2 애니메이션 완료가 아니다.
- [유진](../src/nexus-first-rival.ts): 첫 만남 뒤 비버니 Lv5와 선택 친선전. 실제 전투의 만남/시작/참여/종료/승리를 분리하고 승패와 중단 모두 도윤의 응급 처치로 HP/PP를 회복한다. 상금 없음, 승패 뒤 재대전 없음, 중단은 다시 제안. 이동 잠금 없음. 원고의 **잔모래 센터 동행·재회는 아직 연결하지 않았다**.
- 기존 v1은 새 도입이나 신규종으로 자동 변환하지 않는다. `newSave()`는 구형 생성 계약, `Engine.freshSave()`는 `newNexusSave()`다. v2 읽기와 새 사본 활성화를 사용하며 실제 사용자 저장은 조회하지 않았다.
- 등록 순서는 체육관 특수 처리 → 일반 도로 트레이너 → 첫 여정 등록 → 도시/여행/일반 대사다. 무쇠게이트 작업자 배틀과 첫 배지 축하 우선순위를 보존했고 중복 호출을 제거했다. 축복의 다음 길은 실제 203번도로, 배지 뒤는 204·험한샛길·꽃향기 안내로 고쳤다.
- 장면 완료 콜백은 저장 객체/맵/좌표/장면 번호와 단일 실행을 검사한다. 새 이름 입력의 한글 조합·게임 키 충돌을 처리하고, 기존 리포트 확인으로 나가면 자동 재표시를 미뤄 복구/불러오기를 사용할 수 있게 했다. 필드·폼 화면은 아직 보지 않았다.
- 현재 시작 공간은 여전히 `town` **새잎마을과 기존 연구소**를 재사용한다. 수령 출처도 실제 표시명과 맞췄다. 떡잎/잔모래의 최종 공간 역할 분리·호수 원고 전체 연결은 남아 있다.

## 기존 증거와 미검증

2026-09-20 보고에는 컴파일 복구·모듈 순환 해소·PP 수정, 당시 796통과/602실패와 일부 집중 검사가 기록돼 있다. 이는 [당시 보고](archive/SINNOH_HISTORY.md#record-nexus-cycle-and-oreburgh-20260920)의 결과다. 현재 트리의 PASS가 아니며 2026-09-22 미검증 코드가 추가됐다.

최근 구현은 [무쇠 통합 기록](archive/SINNOH_HISTORY.md#record-nexus-oreburgh-city-20260922)에 있다. 현재 실제 사용자 저장 위치·내용은 이번에 읽지 않았다. 기존 첫 배지 자연 진행 보고도 새 스타팅·새 경로·새 원고의 수용 증거로 승격하지 않는다.

## 협업과 보존 경계

구현 착수 시 앱의 현재 작업 목록에서 같은 저장소의 최근 별도 작업은 idle로 표시되었다. 이번 하위 작업은 저장/패널, 초기 연결, 시계 모듈, 정적 검토로 파일 소유를 나눴고 공통 엔진은 주 담당자가 통합했다. 과거 배정·잠금은 현재 명령으로 승계하지 않았다.

이번 구현은 기존 무쇠·동료·지역 작업과 문서 재편의 변경을 보존했다. 저장 보호·초기 연결·시계에 더해 이벤트 등록·도입·스타팅·유진 회귀 원고를 추가했으며 실행하지 않았다. v2 기본 시작에 영향받은 기존 검사 82파일의 초기 설정도 명시적인 v1 생성/필드 패널로 분리했다. 이 수정에서는 기존 단언을 완화하지 않았다. 신규종 자산 검사는 SVG 경로/출처로 구분하고 기존종 PNG 검사는 보존했다. 기존의 낡은 지역/대사 기대값 전체를 정리하거나 PASS로 선언하지 않았다. 독립 소스 검토와 참고 자료 대조를 수행했다. 갱신 문서의 로컬 링크 219개는 누락이 없고 일반 Git 설정의 diff 공백 확인은 통과했다. 테스트 작성 수나 문서 점검을 실행 수용으로 계산하지 않았으며 테스트·타입검사·빌드·브라우저·저장·시청각 QA는 하지 않았다. 이번에는 스타팅 입력/익스포터·오프라인 생성 데이터·public 자작 SVG를 변경했다. 생성은 구현 산출물 작성이며 실행 QA가 아니다. 설정·의존성·서버·자동화·커밋·푸시는 변경하지 않았다. 루트 AGENTS.md는 기존 삭제 상태다. 과거 배정·작업 위치·검사 이력은 [이전 인계](archive/2026-09-22-rebaseline/CONTINUE_STATE.md)와 [과거 통합 기록](archive/README.md)에 남겼다. 중복 상태 사본과 회차별 파일은 삭제했다.

## 갱신 방법

이 파일은 최신 한 판만 유지한다. 구현 변경 뒤 해당 표의 근거·상태·남은 차이를 바꾸고, 고유한 실패·검증 근거는 archive의 해당 통합 기록에 남긴다. 과거 상태를 앞에 계속 붙이거나 회차 문서를 새로 늘리지 않는다. 다음 실행 작업은 로드맵에서 관리한다.
