# 네 지방 맵·스토리 적용 설계

2026-09-10 크기 기준 보완: [맵 크기 기준·전체 대장](MAP_SIZE_STANDARDS.md)에 사용자 참고표보다 넓힌 유형별 범위, 현재402개 맵의 실제/목표 크기, 신규 도로·던전의 층별 크기를 명시했다. 이 문서의 현재 크기 기록은 이력이며 새 목표 크기는 해당 대장을 따른다. 게임 확대는 미적용이다.

2026-09-10 웹 조사와 저장소 분석을 반영한 설계 문서. 이번 요청은 문서 전용이며 아래 신규 맵·이벤트·명칭 이행은 구현 완료가 아니다. [출처 대장](REFERENCE_RESEARCH.md)의 S/K/J/U 근거와 [WORLD_ROUTES](WORLD_ROUTES.md)를 함께 읽는다. 상위 작업은 지방, 구현·QA 완료 단위는 도시 하나와 담당 진입/출발 구간이다.

## 1. 현재 저장소와 목표의 차이

## 2. 구현 순서와 도시 담당 경계

아래는 후속 구현용 순서다. 문서 개정으로 현재 배정·저장 위치·진행 중 QA를 바꾸지 않는다. 첫 단계는 해당 대화의 CONTINUE_STATE 도시 완료이며, 그 뒤 신규 지리 복원 후보를 선택한다. 사용자가 특정 도시를 지정하면 해당 도시와 그 의존 구간부터 수행한다.

| 단계 | 담당 도시 / 범위 | 다음 행동과 완료 조건 | 선행 조건 |
| --- | --- | --- | --- |
| 현재 관동 | 갈색 | 작업 부두→여객 터미널→주택/보급→기존 운하 귀환과 출발 안내를 통합. 전체 도시 완료 뒤 QA | 갈색 외부·해안길 미커밋 구현과 실제 저장 보존 |
| 현재 신오 | 영원 | 역사관 답사·석상·숲 돌담·3초 관측·유채 목표의 연결과 남은 도시 QA 완료 | 답사 flags와 기존 관장 조건 유지 |
| 현재 성도 | 금빛→고동 | 금빛 계획 구현 완료 후보를 보존하고 고동 외부·필수 실내·너도밤나무숲56×64·33번도로→연결동굴1층→32번도로, 낮 조우와 선택 실전을 적용. 모든 QA 중단 | 실제 포획·학습 저장을 준비 사본으로 되돌리지 않음. QA 재개 전 고동 구현을 완료로 보고하지 않음 |

맵 수 59~68 같은 과거 예상치는 예산 참고일 뿐 완료 목표가 아니다. 도로 번호·층·수단 변화는 구역 경계로 기록하고, 하나의 맵에 함께 둔다면 구역별 지명과 스토리 상태를 구분한다. 도시 사이 거리는 원작 걸음 수 복제가 아니라 진입→지형 변화→관찰/도전→재합류→도착이 화면에서 읽히는 정도로 설계한다.

## 3. 맵별 공통 요구 양식

각 행을 실제 도시 작업 명세로 옮길 때 담당자 대신 담당 도시를 고정한다. 숫자는 미정이면 미정으로 두고 다음 항목을 빠뜨리지 않는다.

| 항목 | 기록할 내용 |
| --- | --- |
| 식별·근거 | 원작 버전, 공식 지명, 프로젝트 변형 이유, 원본 URL/절, 기존 MapId·신규 ID 후보 |
| 연결 | 출발지→각 경유지→도착지, 본선/선택/귀환, 도시 인계 경계, 이동 방식 |
| 공간·화면 | MAP_SIZE_STANDARDS의 현재/목표 가로×세로·층별 크기, 입구 목표물, 큰길·루프·관찰자리, 높이/물/빛, 건물 지붕·문·그림자, 화면 전환 |
| 포켓몬 | 서식 이유·방식·시간대, 참고 종과 실제 지원종, 안전 큰길, 트레이너 시야, 잡은 동료가 도시에서 할 수 있는 행동 |
| 이야기 | 온 이유→플레이어 행동→확인 가능한 변화→다음 목적. 원작 사건/프로젝트 확정 사건/설계 제안 표시 |
| 상태 | 기존 flags 읽기, 신규 상태 제안, 취소/재방문/패배/저장 복귀, 선택 활동이 통행을 막는지 여부 |
| 이행 | 현재 위치·복귀점·도감/포획 출처·방문 수첩·길안내·개발 지도에 미칠 영향 |
| 도시 수용 | 왕복·퍼즐 재시도·필수 실내·포켓몬·이야기·화면/소리의 도시 단위 확인. 개별 맵마다 전체 QA 반복 없음 |

DP풍 공통 표현은 얇은 윤곽·단계형 명암·일관된 빛 방향·지붕과 벽의 높이·작은 인물의 읽히는 실루엣으로 정한다. 하나의 도시 구조와 지형은 유지하면서 화면 표현을 통일한다. 바다·강·운하, 암흑굴·전기 결정굴·얼음굴에는 각각 다른 지면 경계·소리·움직임을 준다. 실제 자산 제작은 후속 구현 범위다.

### 4.1 산로마을 도착 묶음

궐수 다음 본선은 공식 도로 번호가 없는 **궐수 공항→산로마을 항공편**이다. `tour_lentimas` 40×36 외부에는 흙 착륙장, 붉은 화산재 언덕, 재바람 휴게뜰, 도자기 건조장, 동쪽 리버스마운틴 진입 표지를 적용했다. 주민은 기체와 포켓몬의 재 제거, 급수·휴식, 화산 흙 생활, 산길 준비를 맡는다. 콩둘기는 붉은 바위 그늘에서 재를 털며 환경에 반응한다. 궐수행 조종사를 통해 언제든 귀환할 수 있다.

산로마을 담당 구간은 동쪽 리버스마운틴을 지나 물결마을 서쪽 절벽에 도착하는 지점까지다. 센터 28×22, 상점 24×20, 세 주택 각 3층 24×18, 산길 안내소 3층 28×24를 적용했다. 안내소 준비표에서는 건강한 동료를 직접 선택하거나 혼자 물·마른 천·귀환 방향을 점검해 선택 기록만 저장한다. 동쪽에는 외부 56×48→통과구역 A 64×56→B 56×56→물결마을 48×40을 왕복 연결해 재바람 능선→식은 용암층·증기→고온 지면 우회→서늘한 바람 홈→바닷바람 도착을 구성했다. 물결마을은 필수 실내와 동행 손질을 갖추고, 동쪽 13번도로 36×96은 해안 전망→절벽 샘·숨은동굴 흔적→고지 초원을 지나 보배마을 방향 경계까지 연결된다. 다음 도시 단위는 보배마을 40×40과 13번도로 북쪽 출구의 실제 왕복이다. 조우종, 아이템, 트레이너, 원작 사건은 데이터와 이야기 범위를 확정하기 전 생성하지 않는다. 비행 장면은 남아 있으며 전 범위는 QA 중단으로 미검증이다.

보배마을 외부 40×40과 13번도로 북쪽 출구를 연결했다. 마을의 현재 구현 범위는 오래된 성벽, 공동 안뜰, 식재료 건조 생활, 남쪽 13번도로 귀환, 서쪽 12번도로 방향 경계다. 확인되지 않은 전설 사건과 공포 전승은 생활 기록과 구분하고 본편 사실로 확정하지 않는다. 다음 하위 단계는 보배 필수 실내와 성벽 생활 기록이며, 다음 이동 인계는 공식 12번도로 72×32다. QA 중단으로 전 범위는 미검증이다.

## 9. 후속 구현의 완료 판단

각 맵 행은 도시 완료를 위한 하위 요구다. 개발 중에는 필요한 최소 확인만 하고, 담당 도시의 외부·실내·스토리·생태·출발까지 구현된 뒤 왕복 이동, 선택 활동 취소/재방문, 퍼즐 재시도, 포획 출처, 저장/복귀점, 화면·소리를 모아서 검증한다. 이번 문서 작업에서 브라우저 도시 QA나 전체 테스트/빌드를 수행하지 않았다.

이번 조사에서 확정하지 않은 항목은 신규 본편 인물/대사·전설 획득·배지 재배열·통행 잠금·자전거/수상 이동 지급 조건·B2/W2 전용 지형 선택·정확한 후반 레벨 곡선이다. 이 항목이 없어도 진행 가능한 기존 도시·고유 지형·동료 생활 요구는 분리해 구현할 수 있다. 구체 수치는 단일 도시 착수 때 원자료와 실제 지원 데이터를 대조한다.
