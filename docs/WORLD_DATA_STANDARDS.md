# 공통 데이터 기준 — 통합 안내

문서 분류: **호환 안내** · 2026-09-22.
공통 논리 모델·출처 버전·안정 키·생성/실행/저장 경계는 [RUNTIME_DATABASE](RUNTIME_DATABASE.md)로 통합했다.
이 파일은 생성기와 기존 문서의 링크를 보존한다. 새 계약이나 현황을 이곳에 중복 작성하지 않는다.

- 확정 서사: [NEXUS_MAIN_STORY_CANON](story/NEXUS_MAIN_STORY_CANON.md).
- 기술·저장 이행: [DEVELOPMENT](DEVELOPMENT.md).
- 지리·경유·출구·교통: [WORLD_ROUTES](WORLD_ROUTES.md).
- 콘텐츠 제작·도시 완료: [MAP_STORY_DESIGN](MAP_STORY_DESIGN.md).
- 지역별 구현·검증 이력: [과거 통합 기록](archive/README.md).

## 현재 수량과 코드 대조

기존 코드 대조표 링크의 현행 목적지는 [PROJECT_STATE](PROJECT_STATE.md)다.
지원 기능과 미지원 범위는 [통합 데이터 계약](RUNTIME_DATABASE.md)을 따른다. 과거 날짜의 종·풀·기술·맵 수량은 최신 사실로 재사용하지 않는다.
생성 입력 문서와 파서·출력 경로는 [생성 입력과 실행 소비](RUNTIME_DATABASE.md#생성-입력과-실행-소비)를 따른다.
QA는 중단 상태이며 이 통합으로 코드·JSON·자산·저장을 변경하거나 실행하지 않았다.
