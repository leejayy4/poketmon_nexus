# 문서·운영 결정 이력

이 파일은 이전 문서 개정과 운영 판단을 추적하는 **과거 기록**이다. 당시 배정·다음 작업·QA 재개·완료 표기는 현행 우선권이나 실행 허가가 없다.
현재 기준은 [문서 안내](../README.md), [비전·결정](../NEXUS_GOAL.md), [확정 서사](../story/NEXUS_MAIN_STORY_CANON.md)를 따른다. 아래 원래 경로는 통합 출처이며 현존 파일 링크가 아니다.
문서 개정·정적 조회·대상 검사·자연 진행의 근거를 구분한다. 이 통합 과정에서 코드 변경이나 게임 QA를 수행하지 않았다.
