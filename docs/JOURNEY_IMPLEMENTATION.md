# 포켓몬 모험 확장 · 구현과 검증

2026-09-07 사용자 직접 요청. 기존 개선 목록 1~9를 따라 동료 수집·성장·마을 생활을 실제 플레이에 연결했다. 외부 개발 UI 개편(10번)과 전체 캠페인 수용 작업(11번)은 제외했다. 진행 중이던 기존 작업을 보존하고 서브에이전트가 데이터·지도·음향·주민 활동을 나눠 구현했다.

## 실제로 달라진 플레이

| 요구 | 현재 구현 | 남은 범위 |
| --- | --- | --- |
| 새로운 동료 | 기존 설계 DB의 5개 조우표를 실제 풀밭에 적용. 야생 19종, 선물·첫 진화를 합쳐 소유 가능 26종. 장소별 가중치와 레벨 범위 유지 | 모든 지방·모든 통로 조우, 밤·낚시 조우, 마을에서 보이는 모든 종의 획득 |

| 도시의 행동 | 축복 직원 동료 소개, 무쇠 광부 파티 준비 부탁. 각각 일회 보상·재방문·배지 반응. 서쪽길·암반굴의 선택 일반 트레이너전 | 라이벌·도시 문제 해결·관측 사건의 본편 전개 |
| 생활 공간 | 주요 35마을 상점·주택, 56동의 3층 왕복 계단, 거실·작업방·자료실·정원 배치 | 모든 도시의 개별 미술 검수, 엘리베이터, 층마다 고유 서비스 |
| 기술과 소리 | 기술 계열별 18개 시각 스타일과 합성 효과음, 마을·도로·동굴·야생전·관장전 음악, 승리·포획·진화 곡 | 종별 울음소리, 모든 기술의 개별 연출, 장시간 대사 템포 측정·음향 청취 평가 |
| 돈과 준비 | DB 가격(볼·상처약 각 200원), 수량 선택·구매 확인·잔액 검사. 첫 배지 전 무료 보급, 이후 상점 보급. 회복은 무료 | 더 많은 상품과 경제·난이도 장기 균형 |

391개는 현재 사용 맵 수이며 완성된 이야기의 분량을 뜻하지 않는다. 상점 40실은 백화점 판매층을, 주거 159실은 위층을 포함한다. 계단 168개 층은 56동 × 3층으로 집계한다. 서로 다른 집계를 합산하지 않는다.

## 실제 브라우저 검증

`http://localhost:5173/?qa=journey-20260907`의 분리 저장으로 확인했다. [생성기](../scripts/journey-fixtures.ts)가 만든 유효한 QA 파일을 게임의 파일 불러오기 UI로 가져오고, 이동·대화·메뉴는 실제 키보드 입력으로 조작했다. 런타임 내부 값 직접 변경은 사용하지 않았다. 아래는 직접 관찰한 결과이며 새 게임부터 진행한 캠페인 수용 검사는 아니다.

| --- | --- |
| 축복 상점 현관 → 점원 → 볼 5개 구매 | 실제 실내 진입. 돈 5000→4000, 볼 20→25. 수량·구매 확인 메뉴 작동 |

화면은 세션에서 직접 열어 확인했으며 이 기록에 새 PNG 파일로 보관하지 않았다. 음향은 코드·오디오 테스트로 확인했고 실제 청취 평가는 하지 않았다. 전체 도시·전체 캠페인 검증 및 장기 난이도 조정은 남아 있다.
