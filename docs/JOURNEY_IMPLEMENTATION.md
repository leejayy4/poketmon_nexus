## 최초 모험 확장 이력 — 2026-09-07

이하 표와 5개 조우 풀·26종·368개 테스트, 브라우저 관찰은 최초 확장 당시 기록이다. 당시의 두 기술·4기술 미구현·일반 트레이너 두 명 표기를 현재 한계로 사용하지 않는다. 최신 수량과 기능은 위 현황과 연결된 현재 기준 문서를 우선한다.

2026-09-07 사용자 직접 요청. 기존 개선 목록 1~9를 따라 동료 수집·성장·마을 생활을 실제 플레이에 연결했다. 외부 개발 UI 개편(10번)과 전체 캠페인 수용 작업(11번)은 제외했다. 진행 중이던 기존 작업을 보존하고 서브에이전트가 데이터·지도·음향·주민 활동을 나눠 구현했다.
