> **현행 작업 기준:** [지방별 구현 지시](REGIONAL_IMPLEMENTATION_DIRECTIVES.md)를 필수 우선 적용한다. 현재 담당 도시와 남은 작업은 CONTINUE_STATE를 확인하고 과거 도시명/다음 단계로 배정을 바꾸지 않는다. 현지 포켓몬·성장·사건·다음 경유를 기존 장소에 연결한다. 현재 QA는 중단이며 운영 정책은 루트 AGENTS를 따른다.

> **시각 목표 변경 · 2026-09-12:** 현재 목표는 [BW·BW2풍](VISUAL_STYLE_BW_BW2.md)이다. 아래 DP/Pt 원작·자산·적용 보고는 기존 출처와 구현 이력이며 새 목표가 아니다. 그래픽 전환 완료를 뜻하지 않으며 모든 QA 중단을 유지한다.

> **2026-09-12 채택 설계:** [넥서스 통합 서사](NEXUS_STORY_MASTER.md)를 본편 인과관계·인물 성장·배지와 사건 분리·최종장 기준으로 적용한다. 아래 과거 미승인 표기는 작성 당시 이력이다. 이번 채택 범위도 런타임 적용 완료를 뜻하지 않는다. 일반 이동·저장·현재 도시 작업을 보존하고 모든 QA 중단을 유지한다.

2026-09-10 크기 기준 보완: [맵 크기 기준·전체 대장](MAP_SIZE_STANDARDS.md)에 사용자 참고표보다 넓힌 유형별 범위, 현재402개 맵의 실제/목표 크기, 신규 도로·던전의 층별 크기를 명시했다. 이 문서의 현재 크기 기록은 이력이며 새 목표 크기는 해당 대장을 따른다. 이후 적용된 맵은 제4·6절과 CONTINUE_STATE의 최신 구현 기록을 따르며, 대장의 목표값만 있는 행은 아직 런타임 적용으로 보지 않는다.

## 1. 적용 범위와 읽는 순서

- 신오의 도시·도로·동굴·야생 조우·트레이너·시설·체육관·그래픽·음향을 작업할 때 이 문서의 해당 지역과 이동 구간을 먼저 확인한다.
- 실행 절차는 [AGENTS.md](AGENTS.md), 현재 구현 계약은 [DEVELOPMENT.md](DEVELOPMENT.md), 확정 사건·플래그는 [STORY.md](STORY.md)가 담당한다. 이 문서는 신오 도시 요구와 기존 연결 키를 관리한다. 신규 지리·표시는 WORLD_ROUTES, 맵별 행동·스토리는 MAP_STORY_DESIGN이 기준이다.
- [공통 데이터 기준](WORLD_DATA_STANDARDS.md)은 종·기술·아이템의 지방 공통 규칙, [공통 도로 명세](WORLD_ROUTES.md)는 현재 출구와 원작 참고 경로를 담당한다. 공식 번호·고유명은 신규 표시 기준이고 이 문서의 옛 번호는 내부 이행 자료다. 예를 들어 프로젝트 신오 6번도로는 연고–장막 연결 전체를 가리키며 원작 참고의 여러 도로 번호를 대체하는 공식 명칭이 아니다.
- 최신 사용자 요청과 현재 [이어받기 기록](CONTINUE_STATE.md)을 우선한다. 이 문서를 추가했다고 관동의 진행 중인 작업을 신오나 첫 배지로 되돌리지 않는다. 신오 작업이 선택되었을 때 해당 묶음부터 적용한다.
- 이전 제안의 탐험·육성·도시 활동·생활 연출·전투 보강을 아래 요구로 기록한다. 신규 인물·조직·라이벌·본편 사건·전설 획득·다섯 번째 이후 체육관·지역 잠금은 이 문서만으로 확정하지 않는다.
- 원작 전체 지도를 복제하는 계획이 아니다. 현재 창작 출발 마을과 도시 연결을 유지하면서 지역 경험을 확장한다. [장기 초안 맵](개발용_초안맵.md)의 S/CH/SQ 노드와 미확정 사건을 현재 연결에 자동 반영하지 않는다.

## 3. 모든 신오 여행 구간에 적용할 요구

1. **이동과 탐험:** 출발 도시→번호가 있는 도로/동굴→도착 도시를 명확히 표시한다. 큰길, 선택 포획로, 트레이너 자리, 탐험 뒤 복귀 동선을 함께 설계한다. 이동 거리만 늘리거나 빈 지도를 추가하지 않는다.
2. **서식지와 성장:** 출현종·레벨·기술·진화·다음 전투를 함께 확인한다. 잡은 동료가 해당 여행에서 활약할 이유를 제공한다. 풀밭 그림만 있고 조우가 없는 상태는 조우 구현으로 보고하지 않는다.
3. **트레이너:** 첫 배지 이후 도로에 실제 배틀을 배치한다. 지역에 맞는 파티와 교대·상성·변화기 등 전투 목적을 정하고 길이와 회복 간격에 맞춰 수를 조정한다. 새 강제 차단·필수 승리 조건을 임의 추가하지 않는다.
4. **도시 활동:** 도시마다 실제 조작하는 대표 활동 하나를 먼저 완성한다. 견학·대사·층 이동과 활동의 실제 실행을 구분한다. 활동 보상·소비·반복 여부는 구현 전 해당 작업에 명시한다.
5. **생활과 세계관:** 기존 주민과 포켓몬의 작업·휴식·훈련·놀이를 짧은 행동으로 보여 준다. 재방문·배지·파티에 대한 반응을 활용한다. 대사 수집을 필수 체크리스트로 만들지 않는다.
6. **신오의 공간감:** 산의 암반·높이 차, 오래된 석조물, 숲과 호수, 관측 시설의 모양과 배치를 인접 구간까지 연결한다. DS BW·BW2풍 타일·외관·전투장·효과음의 일관성을 유지한다.
7. **기존 이야기 연출:** '3초 어긋남'은 시계·관측 기록·장치 조사와 연결할 수 있다. 기존 사건을 시각화하는 범위와 새로운 원인·사건·완료 플래그를 만드는 범위를 구분한다.
8. **규모와 검증:** 도시 면적의 일괄 배율 확대보다 기능별 구역, 숲·산의 연결된 탐험 구역을 우선한다. 맵 확장에 따른 경험치·회복·보급 부담을 확인한다. 개발 중 최소 확인·실제 오류 해결과 도시 완료 후 QA는 상세 작업 규칙을 따른다.

## 5. 도로·동굴 번호 규칙

**이 문서의 번호는 프로젝트 고유 번호이며 원작 공식 도로 번호가 아니다.**

기존 프로젝트1~12·동굴1~2는 레거시 연결을 찾는 내부 별칭이다. 신규 표시는 WORLD_ROUTES의 공식 번호·고유명을 따른다. 예를 들어 축복–무쇠는203+무쇠게이트로 분리하고, 분리 전 통로는 현행 고유명으로 구분한다. 새로운 공식풍 번호를 생성하지 않는다.

`S01~S20`은 설계 권역, `ENC-xxx`는 조우표, `tour_*`는 맵 ID다. 같은 숫자라도 대응을 추정하지 않는다. 표의 옛 표시 예를 재사용하는 대신 공식명/창작명·구간·MapId·출처 별칭을 MAP_STORY_DESIGN 양식으로 기록한다.

## 8. 신오 작업 순서와 완료 조건

현재 신오 영원시티와 다른 지방의 이어받기를 교체하지 않는다. 옛 프로젝트 번호를 기준으로 한 작은 구간 순서 대신 [맵·스토리 설계](MAP_STORY_DESIGN.md#2-구현-순서와-도시-담당-경계)의 도시 단위 순서를 따른다.

1. **현재 영원 완료:** 남북 접근로·숲·역사관·정원·기존 유채 목표와 출발 안내의 남은 도시 QA를 마친다. 아직 확인하지 않은 항목을 완료로 바꾸지 않는다.
2. **신규 지리 후보:** 시작권역 프롤로그 결정 후 잔모래 도착을 구현하고, 그다음 축복의202번 접근을 별도 도시 단위로 이어간다. 기존 첫 배지 QA를 반복하기 위한 재시작이 아니다.
3. **사용자 지정 후속 도시:** 연고라면206·207·천관산·208과 공연 생활, 장막이라면 신수 작업과209·210남·215의 인계 경계를 먼저 정한다. 기존 네 배지·자료 전달 이야기와 동료 성장의 연속성을 보존한다.
4. **그 밖의 후속 확장:** 들판의 습지, 물가의 해안, 선단의 설원/호수, 운하218을 각 도시에 귀속한다. 호수 전설·미확정 체육관·조직 사건은 장소 추가만으로 확정하지 않는다.

각 도시의 진입 구간과 다음 출구 인계점을 정하고, 작업 시작 시 도시·실제 경유지·목표·완료 조건·변경 파일을 명시한다. 공유 구간의 구현 담당은 하나로 두며 현재 MapId와 신규 공식 구간을 구별한다. 각 도시의 수용 기준은 다음과 같다.

- 번호와 양끝 목적지가 지도·표지·안내에서 일치하고 왕복 출구와 이전 저장 복원이 유효하다.
- 큰길과 선택 탐험로가 연결되며 지역의 조우/트레이너/회복 간격이 실제 여행을 구성한다.
- 포획한 동료가 성장·배틀·도시 활동에서 활약하고, 지역 고유 활동 하나를 직접 실행할 수 있다.
- 체육관 또는 도시 활동 뒤 다음 구간까지 자연스럽게 이어지고 실제 DS 화면과 음향 적용 범위를 확인한다.

완료 후 해당 행의 적용 상태와 근거를 갱신하고 실제 구현 회차의 CONTINUE_STATE에 변경/검증/남은 문제/다음 작업을 기록한다. 문서만 수정한 회차는 구현 회차 수에 더하지 않으며, 진행 중인 게임 인계를 덮어쓰지 않는다.

## 2026-09-12 신오 본편 적용 계약

출발권역의 평범한 생활·파트너 관계·3초 관측 원본을 먼저 쌓는다. 귀환 시 같은 장소의 관계를 회수하고 권장 배지 도전 뒤 국소 이상을 다룬다. 대규모 풍경 중첩은 CH09 시간·공간 사건 뒤다. 창기둥 전투와 깨어진세계 구조를 분리한다.
