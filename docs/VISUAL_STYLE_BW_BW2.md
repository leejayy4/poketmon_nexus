# BW·BW2풍 시각·연출 기준

2026-09-12 사용자 결정: 포켓몬 넥서스의 시각·연출 목표를 **Nintendo DS 포켓몬스터 블랙·화이트 / 블랙2·화이트2풍**으로 승격한다. 이전 DP/플라티나풍 유지 지침을 대체한다. **목표 변경이며 현재 그래픽의 전환 완료가 아니다.**

## 범위와 책임

- 네 지방 모두 같은 BW·BW2풍 표현 기준을 적용한다. 관동·성도·신오의 도시 디자인을 하나의 현대 도시로 바꾸지 않는다. 각 지방 고유 지리·건축·생태는 지방 문서와 WORLD_ROUTES를 따른다.
- [통합 서사](NEXUS_STORY_MASTER.md)의 사건·인물·순서, 현재 파티·맵 ID·저장·교통을 보존한다. 그래픽 승격으로 전체 전투 규칙·기술표·등장종을 자동으로 5세대에 고정하지 않는다.
- 현재 Canvas 기반 필드와 기존 DS 자산은 이행 출발점이다. 실제 3D 지형·회전 카메라·BW형 애니메이션이 이미 지원된다고 가정하지 않는다. 렌더러 교체나 새 엔진·의존성 도입은 이번 문서 작업에 포함하지 않는다.
- 본 문서는 목표 품질의 단일 기준이다. DEVELOPMENT는 현재 기술 계약, REFERENCE_RESEARCH는 원작 자료·출처, 지방 문서는 도시별 적용 범위, CONTINUE_STATE는 실제 진행을 관리한다.

## 지방별 번역 기준

| 지방 | 보존할 정체성 | BW·BW2풍으로 보강할 표현 |
| --- | --- | --- |
| 신오 | 산악·호수·광산·석조 유적·설원 | 능선과 고저차의 겹침, 물가 반사, 광산 깊이, 귀환 전후 장면 변화와 창기둥 구도 |
| 관동 | 오래된 도시·연구시설·항구·주거·섬 | 노랑의 수직 거리, 갈색 항만의 움직임, 홍련 연구 구역/해안의 대비. 전통 주택을 하나 빌딩으로 일괄 교체하지 않음 |
| 성도 | 목조·기와·탑·전승·숲·호수 | 탑의 높이와 단풍 전경, 숲의 깊이·빛, 마을 공방의 움직임, 호수/섬의 물길 |
| 하나 | 대도시·철도·교량·사막·유적·항공·해안 | 구름 거리의 원근, 교량을 건너는 구도, 시설과 주민 움직임, 전기돌/고대성의 깊이. B2W2 지리와 NEXUS 본편 배치 구분 |

도로·동굴은 도시 사이 빈 통로가 아니라 다음 장소가 다가오는 경험을 만든다. 도시 경계의 건축/식생 변화, 중간 전망·쉼터·분기·발견을 배치한다. 실제 경유 번호·고유명·MapId·귀환은 WORLD_ROUTES, 현재/목표 크기는 MAP_SIZE_STANDARDS를 단일 기준으로 유지한다.

## 적용 순서와 완료 표현

1. 현재 담당 도시와 진입 도로/동굴을 유지한다. 새 스타일 때문에 네 지방을 모두 초기화하거나 완료 이력을 지우지 않는다.
2. 해당 도시의 외부·필수 실내·캐릭터·전투장·핵심 사건에 대해 `현재 표현 / 목표 표현 / 필요한 자산·렌더링 지원 / 기존 저장·출구 영향`을 정리한다.
3. 길·출구·건축 실루엣·깊이를 먼저 맞추고, 생활 움직임·카메라·배틀·이벤트 연출을 같은 도시 경험에 통합한다. 이름만 BW로 바꾸거나 정지 이미지 교체만 하고 승격 완료로 보고하지 않는다.
4. 신규 자산에는 원작/자작/가공 출처, 참고 버전, 파일·프레임·투명도·기준점을 기록한다. 이전 DP/Pt 자산의 출처를 BW로 바꿔 쓰지 않는다.
5. 상태는 `BW·BW2 목표 채택 → 도시별 이행 설계 → 부분 구현·미검증 → 도시 구현 완료 후보 → 사용자 QA 재개 후 검증`으로 구분한다. 새 테스트·빌드·브라우저·시각/음향/저장 QA는 현재 모두 중단한다.

- [BW 공식 소개](https://www.pokemon.co.jp/series/bw/): 원작 화면·지역과 시스템을 구분해 참고할 공식 출발점.
- [BW2 공식 사이트](https://www.pokemon.co.jp/ex/b2w2/), [모험의 무대](https://www.pokemon.co.jp/ex/b2w2/story/): 하나지방의 후속 시점과 원작 소개. NEXUS가 같은 연대기라는 뜻은 아니다.
- [Nintendo 개발자 인터뷰](https://iwataasks.nintendo.com/interviews/ds/pokemon-black2-white2/0/0/): DS 후속작 제작 배경 참고.

2026-09-12 공식 페이지 검색 결과를 확인했다. 전체 화면·프레임·카메라 수치 분석이나 자산 취득을 수행한 기록은 아니다. 위 표현 표의 수치 미지정 항목은 프로젝트 목표이며 원작 엔진 사양으로 인용하지 않는다.

> **2026-09-12 하나 설화 부분 이행:** 설화시티의 공통 눈 테마 위에 빗물 연못·습지 생활 뜰·용나선 전망 둔덕·실제 동문/북문을 구분하는 석재 물턱, 갈대, 건조 난간, 높이띠와 독립 반복 움직임을 적용했다. 실내에는 차가운 벽 재질과 습지 기록 설비를 겹쳤다. 외부→센터 실제 이동과 화면·콘솔은 확인했지만 실제 소리 청취와 생활관·주택 전 층 화면 수용은 남아 있어 **도시별 부분 구현·QA 보완 중**이다.

> **2026-09-12 하나 설화 음향 이행:** 설화 외부·실내, 8번도로, 설화의 습지, 용나선 남쪽 접근로에 원작 음원을 복제하지 않은 짧은 자작 선율의 `icirrus` 장면을 적용했다. 전투 장면과 튜브라인브리지의 기존 음향 경계는 보존했다. 자동 오디오 검사는 통과했지만 실제 스피커 청취 수용 전이므로 완료 근거로 사용하지 않는다.

> **2026-09-12 하나 설화 연결 구간 움직임 이행:** 하나 8번도로의 웅덩이 잔빛·풀 흔들림, 설화의 습지의 수면 물결·갈대·멀리 도는 물새, 번호 없는 용나선탑 접근로의 수면 잔빛·바람선을 맵별 반복층으로 적용했다. 센터에서 설화 동문·8번도로를 거쳐 습지 남쪽 입구까지 실제 이동해 통로·표지·출구 가림과 콘솔 오류가 없음을 확인했다. 용나선탑 접근로 화면 수용은 남아 있다.

> **2026-09-12 하나 용나선탑 시각 이행:** 기슭의 해자 수면·기단 높이띠·보존 표석, 1층 기단석, 2층 이중 나선 석재, 3층 청록빛 바람 관찰부를 전용 배경층으로 적용했다. 기슭 수면 잔빛과 3층 바람선은 독립 반복 움직임이다. 맵·충돌·워프·관찰 이벤트는 유지했으며 QA 중단으로 실제 화면 수용은 미확인이다.

> **2026-09-12 하나 용나선탑 음향 이행:** 설화와 번호 없는 접근로의 `icirrus` 장면에서 탑 기슭·공개 1~3층의 자작 `dragonspiral` 장면으로 넘어간다. 낮은 석재 울림과 느린 상승 선율로 내부 높이감을 구분하며 원작 음원·녹음 자산은 사용하지 않는다. QA 중단으로 자동 검사와 실제 청취는 미확인이다.

> **2026-09-13 하나 튜브라인브리지·9번도로 시각/생활 이행:** 튜브라인브리지에는 철골 안전등 점멸과 보행 난간 빛 변화를, 9번도로에는 가로수 흔들림·쇼핑몰 나인 외부 창빛과 쌍용 서문 쉼터의 생활 콩둘기를 적용했다. 이동 통로와 출구를 가리지 않는 맵별 반복층을 목표로 했으며, 쇼핑몰 영업·열차 운행·야생 조우를 표현하는 기능은 아니다. QA 중단으로 실제 화면과 반복 움직임 수용은 미확인이다.
