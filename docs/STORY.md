# 이야기의 실행 계약

2026-09-22 재정립. 이 문서는 **채택된 이야기와 현재 코드의 대응·저장 계약**을 관리한다. 줄거리의 재승인 문서나 구현 완료 보고서가 아니다.

## 1. 읽는 기준과 책임

- 인과·인물·세계 규칙·결말은 [메인 확정 기준](story/NEXUS_MAIN_STORY_CANON.md)을 따른다.
- 장면 내용은 [본편 28장](story/NEXUS_STORY_COMPLETE.md), [포켓몬 연작](story/NEXUS_POKEMON_CHRONICLES.md), [고려 원고](story/GORYEO_STORY_COMPLETE.md), [주요 장면](story/NEXUS_KEY_SCENES.md)에 있다.
- 이 문서는 그 내용을 어떤 장소·행동·상태·기존 저장으로 실행할지 정한다. 제작 순서는 [로드맵](STORY_AXIS_ROADMAP.md), 첫 제작 묶음은 [첫 배지 구간](FIRST_BADGE_SLICE.md)을 따른다.

- 과거의 ‘후속 체육관은 권장’, ‘첫 리그는 엔딩 뒤’, ‘아크·라이벌은 미승인’ 문구는 현행 서사 기준이 아니다. 옛 실행 계약을 보존하는 일과 새 본편 목표를 축소하는 일을 구분한다.

## 4. 원고 번호와 저장 상태

`CH00~CH10`, 새 본편 1~28장, `SQ01~16`, `EX01~20`, `PG01~11`, `M01~05`, `KRY01~05`는 서로 같은 번호 체계가 아니다. 편집 번호만으로 실행 플래그를 만들거나 장 완료를 계산하지 않는다.

1. 기존 실행 상태의 생산자와 소비자를 먼저 찾고 새 장면의 의미와 대조한다. 동일 의미만 재사용한다.
2. 방문·생활 관찰·현지 포획·트레이너 승리는 본편 완료 증거가 아니다. 과거 기록을 새 사건 완료로 자동 승격하지 않는다.
3. 새 상태는 의미·값 범위·기본값·생산/소비 위치·보상 중복 방지를 함께 정의한다. 서로 다른 사건을 단일 `completed`에 묶지 않는다.
4. 저장되지 않는 컷신 중간 상태는 마지막 확정 단계에서 안전하게 다시 시작하도록 설계한다. 보상 확정과 연출 재생을 분리한다.
5. 같은 종의 다른 개체나 바뀐 파티 슬롯을 이전 동료로 오인하지 않도록 개체 추적 계약을 적용한다.
6. 상태표의 항목 수나 플래그 수를 장·지방 완성률로 환산하지 않는다.

현재 [저장 해석](../src/save.ts)은 `version:1`, `worldRevision`, 기존 첫 동료 종 목록·수령 플래그, 최대 네 배지와 TM 대응 등을 검사한다. 신규 스타팅·추가 배지를 원고대로 추가하는 것만으로 저장이 호환되지는 않는다.

새 종·배지·장 상태를 활성화하기 전에 해석기와 이행을 함께 설계하고, 기존 소유 개체·기술·배지·보상·방문·교통·복귀점을 보존한다. 검증되지 않은 불일치 저장을 조용히 새 게임으로 바꾸지 않는다.

## 5. 기존 저장을 새 본편으로 옮기는 원칙

- 이미 얻은 신오 네 배지는 첫 지방의 중간 성과로 인정한다. 새 첫 장을 못 봤다는 이유로 회수하거나 관장전을 강제로 반복하지 않는다.
- 다른 지방 선방문과 무료 왕복·조사선 기록은 보존한다. 물리적 방문과 지방 본편 시작/완료를 별도 상태로 다룬다.
- 부족한 필수 정보는 재방문 가능한 현장 장면·기록으로 제공한다. ‘옛날에 보았을 것’이라고 새 사건 플래그를 자동 지급하지 않는다.
- 첫 파트너·피카츄와 하린의 이브이 소유 관계를 보존한다. 신규 스타팅을 기존 파티에 강제 지급·교환하지 않는다.
- 옛 `oreburghRoarkMineBriefed`·생활 기록과 실제 강석 만남을 구분한다. 배지 보유자의 첫 배지 장면은 재방문 축하로 처리하는 현재 분기를 보존한다.
- MapId·플래그를 정리할 때는 별칭/이행 후 유효한 양방향 이동과 안전 복귀 위치를 정한다. 이름 변경만으로 지리 이행을 끝내지 않는다.

## 6. 서사에 맞춘 실행 경계

축복의 첫 징후는 **초침과 계속 흐르는 분수의 차이**다. 주인공 접점 노출은 본편 3장 숲 인근 시험기 고장으로 남긴다. 진실호수나 첫 배지 전에 시간 능력·전설 선택을 추가하지 않는다.

현재 연결은 `tour_jubilife`의 분수 테두리 `(16,19)`·`nexusJubilifeClock`이다. 살펴보기 선택 뒤 4.3초 관찰 안에서 큰 시계만 3초 지연되고 기준 시계·분수는 계속 움직인다. 마지막에만 `nexusJubilifeClockObserved=true`를 쓰며 아이템·배지·통행 조건은 바꾸지 않는다. X/Esc 또는 아래 화면의 그만 보기로 취소할 수 있다. 대기 중 Z/Enter는 완료를 앞당기지 않는다. 저장 객체·맵·좌표·대화가 바뀌면 진행을 폐기하고, 중간 시간은 저장하지 않아 재접속 시 새 관찰로 시작한다. 완료 저장의 재방문은 관찰 기억을 읽는다. 코드 연결 근거이며 실제 입력·타이밍·그림·저장은 QA 대기다.

서진의 첫 구호 만남은 첫 배지 뒤 꽃향기 방향이다. 건강한 파티에 부상을 강제로 만들지 않고 다른 구조 개체를 함께 돌보는 분기를 둔다. 첫 배지 축하 밤에는 습격·세계 위기를 끼워 넣지 않는다.

회상 M01~05는 CANON의 배치를 따른다. 플레이어가 본 과거 회상과 현재 주인공이 확보한 원본·증언은 별개다. 회상 생략으로 필수 정보를 잃지 않게 한다.

선택 SQ·EX는 필수 단서를 독점하지 않는다. 사건 해결과 포획을 나누고 전설 소유 수·SQ 수집 수로 본편을 잠그지 않는다. 선택 이야기는 제작 범위에서 유지한다.

첫 파트너와 파이리의 진화·편성·PC 보관을 인정한다. 장면은 현재 단계·관계 이력에 대응하고 필수 구조는 현재 동료·구조대의 대체 행동으로 성립한다. 강제 진화·동료 삭제·소유 개체의 중복 생성은 하지 않는다.

## 7. 검증·갱신과 과거 기록

**QA 중단을 유지한다.** 명시적 재개 전 테스트·QA용 빌드·브라우저·자연 진행·저장·시각/음향 검증을 실행하지 않는다. 이번 문서 재정립은 코드 적용이나 QA 재개가 아니다.

구현 후에는 해당 표의 행과 실행 근거를 갱신한다. 장면 하나의 코드 반영을 도시 완료로 올리지 않으며, 도시 수용과 첫 배지 전체 자연 진행 수용은 [첫 배지 기준](FIRST_BADGE_SLICE.md)에서 구분한다.

회차별 대사·좌표·진척 로그를 이 문서 아래에 계속 누적하지 않는다. 현재 상태와 인계에는 실제 변경·미검증 범위·다음 작업만 남긴다.

재편 이전 상세 기록은 [STORY 원문 보존본](archive/2026-09-22-rebaseline/STORY.md)에 있다. 옛 ‘확정/미승인/구현됨’ 표현은 작성 당시 기록이며 현행 CANON·코드·검증 상태를 덮어쓰지 않는다.
