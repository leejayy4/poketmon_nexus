## 1. 이 문서의 지위와 확정 범위

사용자가 제시한 여러 기획안을 하나의 개발 가능한 장기 구상으로 정리한다. 아래의 장·퀘스트·인물·진행 규칙은 이번에 작성한 **추천 초안**이다. 문서를 만들었다고 게임 기능이 구현되거나 모든 세부 설정이 최종 승인된 것은 아니다.

| 구분 | 기준 |
| --- | --- |
| 사용자 요구 | 관동·성도·하나·신오를 오가는 큰 이야기, 각 지방 체육관, 지정 전설 11종, 따라큐·피카츄 마을·이브이 진화·빨간 갸라도스, 제시한 인기투표 목록의 포켓몬 등장 |
| 초안 작성 당시 보존 기준 | 새잎마을, 빛나래, 은솔박사, 하린, 도윤, 당시 6개 맵과 첫 파트너 수령 순서, DP/플라티나풍 화면. 현재 구현 수량은 DEVELOPMENT.md를 우선 |
| 이 초안에서 제안 | 신오 출발·귀환 구조, 팀 아크, 공명 계획, 32개 체육관 중 본편 필수 20개, 지역별 리그와 월드 마스터즈, 종별 획득 배치 |
| 구현 시 별도 결정 | 전투 수식·기술 세대 기준, 관장 명단·세부 대사·파티, 이동 기술 규칙, 저장 형식 개정, 자산 제작 범위 |

초안 작성 당시에는 새잎마을의 지방 편입을 제안했다. 현재 프로젝트의 출발 거점·연결은 신오 기준과 WORLD_ROUTES를 따른다. 이 옛 제안을 다시 미결정으로 되돌리지 않는다. 별빛마을·별하늘마을로 이름을 바꾸거나 스타팅을 교체하지 않는다.

현재 선택은 꼬부기 → 파이리 → 이상해씨이며, 연구원에게 반복 대화하면 피카츄를 받을 수 있다. 일반 스타팅 다음 피카츄는 가능하고, 피카츄를 먼저 받으면 일반 스타팅은 받을 수 없다. 하린 곁의 이브이는 현재 생활 NPC다. 리오르·이브이 지급은 여행 중 별도 사건으로 설계한다.

초안 작성 당시 종 데이터는 이상해씨·파이리·꼬부기·피카츄뿐이었고 전투·포획·진화·도로·체육관·교통이 아직 없었다. 현재는 일부가 구현됐으며 정확한 수량은 DEVELOPMENT 82·85절을 따른다. 아래의 설계용 ID는 여전히 실행 코드의 ID가 아니다.

## 2. 원안에서 보완한 결정

| 원안의 문제 | 이 초안의 해결 |
| --- | --- |
| 전설이 매번 장치의 연료가 됨 | 전설마다 발견·추적·구조·협력·대립 방식과 자신의 의도를 준다. 팀 아크가 얻는 것은 불완전한 관측 기록이며 전설 전체를 계속 포획하지 않는다 |

| 모든 후대 포켓몬을 마지막 균열에서만 만남 | 교류·이주·보호 활동으로 초중반부터 만난다. 균열은 후일담의 특별 탐사에 한정 |
| 따라큐 획득이 피카츄 선행 획득에 종속 | 피카츄 마을 완료는 추가 연출 조건이다. 피카츄가 없어도 천을 수선하고 신뢰를 얻으면 완료 가능 |
| 붉은 색과 폭주를 같은 실험 결과로 단정 | 이미 붉은 특징을 가진 잉어킹이 있었고, 강제진화 장치가 폭주를 유발했다고 설정. 색이 다름과 난폭함을 분리 |
| 인기 포켓몬을 NPC가 쓰기만 하고 끝냄 | 목록의 모든 종에 플레이어 획득 경로를 둔다. 진화형은 진화로 획득해도 충족한다 |
| 전설 모두를 잡아야 이야기 이해 가능 | 본편은 목격·구조·협력이 중심. 후일담도 사건 해결로 다음 장을 열며 포획을 강제하지 않는다 |
| 원작 지명과 창작 내용이 혼합됨 | 기존 지방·도시를 바탕으로 한 재구성 세계로 명시. 창작 장소는 맵 문서에서 표시 |

이것은 여러 게임·애니메이션의 사건을 같은 연대기에 그대로 끼워 넣은 공식 후속작 설정이 아니다. 4개 지방을 바탕으로 재구성한 팬게임이며, 관동·성도의 리그 운영 분리, 장치, 조연, 전설의 개입 목적은 이 작품의 창작 설정이다. 인기투표는 사용자가 제공한 **등장 희망 목록**으로만 사용하며 순위·표 수의 진위를 주장하지 않는다.

## 3. 이야기의 중심

**서로 다른 곳에서 살아온 인간과 포켓몬이, 완벽한 하나의 세계를 강요받는 상황에 맞서 각자의 삶을 지키는 이야기.**

여행의 목표는 두 가지다. 트레이너로서는 배지를 모으고 여러 지방의 리그에 도전한다. 사건의 목격자로서는 은솔박사와 지역 협력자에게 정보를 전달하고 현장의 포켓몬을 돕는다. 세계를 구할 운명이나 특별한 혈통을 주인공에게 부여하지 않는다.

질문은 “완벽한 세계를 만들 수 있다면 지금 살아가는 이들의 선택을 지워도 되는가?”다. 답은 마지막 연설 한 번이 아니라 이브이의 진화, 따라큐의 거처, 조로아크의 환상, 라이벌의 행동을 통해 쌓는다.

### 네 지방의 역할

| 지방 | 여행의 분위기 | 사건의 질문 | 중심 포켓몬 |
| --- | --- | --- | --- |
| 신오 | 익숙한 길, 숲과 호수, 산과 고대 유적 | 세계가 변해도 우리가 함께한 시간은 남는가? | 디아루가·펄기아·기라티나, 루카리오 |
| 관동 | 활기찬 도시, 연구시설과 오래된 기록 | 만들어진 생명도 자신의 삶을 선택할 수 있는가? | 뮤츠, 피카츄·이브이·폴리곤 |
| 성도 | 전통 마을, 탑, 호수, 섬 | 상처를 없애는 일과 상처를 돌보는 일은 어떻게 다른가? | 칠색조·루기아·라이코·앤테이·스이쿤 |
| 하나 | 큰 도시, 철도, 옛 성, 공개 토론 | 누구의 진실과 누구의 이상을 세계의 기준으로 삼을 것인가? | 레시라무·제크로무, 조로아크 |

### 공명에 대한 최소 규칙

1. 공명석은 에너지의 근원이 아니라 서로 다른 장소의 반응을 전달하는 희귀한 매질이다. 돌 하나가 모든 전설의 능력을 주지 않는다.
2. 팀 아크는 뮤츠 연구에서 생체 반응 측정 기술을 훔쳤다. 뮤츠의 유전자나 완성된 능력을 복제한 것은 아니다.
3. 각 지방의 중계기는 반응 기록을 쌓는다. 실제 세계를 바꾸려면 창기둥의 고대 접점과 디아루가·펄기아의 개입이 필요하다.
4. 레시라무·제크로무는 정답을 출력하는 기계가 아니다. 사람의 진실·이상에 반응하며 조직의 일방적인 명령에 동의하지 않는다.
5. 죽은 사람의 완전한 복원이나 과거의 마음대로 수정은 성공한 기술로 제시하지 않는다. 팀 아크가 믿는 가능성과 입증된 사실을 대사에서 구분한다.
6. 기라티나의 개입과 뮤츠의 도움만으로 모든 장치가 꺼지지 않는다. 각 지방 동료들의 중계기 차단과 주인공의 현장 행동이 필요하다.

## 4. 주요 등장인물

| 인물 | 출발점 | 변화와 최종 역할 |
| --- | --- | --- |
| 빛나래 — 기존 주인공 | 첫 친구와 모험하고 싶은 초보 | 서로 다른 지역의 사람들을 연결한다. 파동·왕의 혈통 등 독점 능력 없이 행동으로 신뢰를 얻음 |
| 은솔박사 — 기존 인물 | 파트너를 맡기는 박사 | 환경과 포켓몬 반응의 공동 연구에 참여하는 설정을 추가 제안. 연구망을 연결하되 수사·구조를 아이에게 혼자 떠넘기지 않음 |
| 하린 — 기존 연구원 | 이브이와 놀며 서로 알아가는 중 | 무지개시티 연구가와 연락하는 연결자. 연구소 이브이를 말없이 보상으로 전환하지 않음 |
| 도윤 — 기존 이웃 | 정비 중인 서쪽 출구를 지킴 | 최초 도로 구간 구현 시 정비 완료를 알리는 역할. 악당·라이벌이라는 과거를 덧붙이지 않음 |
| 유진 — 라이벌, 가칭 | 배지와 강함을 목표로 하는 동년배 | 관동 구조 활동에서 무력감을 느낌 → 하나에서 아크의 공공 구조 사업에 참여 → 당사자 동의가 지워지는 명령에 반대 → 최종장 피난 경로를 책임짐 |
| 서진 — 아크 책임자, 가칭 | 재난을 겪고 예방 기술을 연구한 과학자 | 모두를 구한다는 목적을 앞세워 타인의 선택을 제거. 마지막에는 계획 중지에 협력하지만 피해 책임과 조사에서 면제되지 않음 |
| 이안 — 아크 현장 연구원, 가칭 | 공개적으로는 환경 복구 프로젝트에 참여 | 성도 실험의 피해를 보고 기록을 전달. 조력자가 되어도 과거 가담을 없던 일로 하지 않음 |
| 지역 관장·연구자·선원 | 각자의 도시에서 살아가는 사람들 | 수사, 대피, 장비 운용을 나눠 맡음. 관장 전원을 악당에게 진 채 기다리는 인물로 만들지 않음 |
| 뮤츠 | 자신을 연구 대상으로 보는 인간을 경계 | 관동에서 주인공이 실험체를 먼저 구조한 일을 기억. 마지막에 스스로 협력하며 조직의 도구라는 역할을 거부 |

팀 아크는 겉으로 재난 예측·서식지 복원 사업을 한다. 초반의 도움이 실제로 일부 사람을 구했기에 지지자가 존재한다. 핵심 지휘부는 위험한 강제 실험을 알고 실행한다. 모든 단원을 동일한 사상가로 만들거나 피해를 좋은 의도로 정당화하지 않는다.

### 관동편의 실제 성과

피카츄 마을의 긴 사연은 선택 퀘스트다. 필수 실프 조사에서 같은 송신 장치의 흔적을 찾으므로 숨겨진 마을을 못 찾아도 본편이 진행된다. 홍련에서는 뮤츠를 포획하거나 쓰러뜨리는 대신 실험체의 탈출을 돕는다. 뮤츠는 멀리서 이를 관찰하고 짧게 개입한다.

플레이어가 끊어낸 복제 회로 때문에 아크는 원래 계획했던 생체 제어망을 완성하지 못한다. 조직은 남은 관측 데이터로 무리한 대체 장치를 만들며 후반 실패의 원인을 스스로 키운다.

### 성도편의 세 전설은 서로 다른 사건

| 전설 | 사건 | 플레이어 행동 | 나중에 달라지는 세계 |
| --- | --- | --- | --- |
| 라이코 | 금빛 북부의 끊어진 전기 흐름을 따라 나타남 | 포켓몬을 소모시키는 축전기를 멈추고 피난 신호 복구 | 밤길의 안내등과 전기 포켓몬 행동 회복 |
| 앤테이 | 황토 산길에서 지열을 빨아들이는 굴착 시설에 접근 | 광부·애버라스를 대피시키고 과열 배관 차단 | 막혔던 산길의 안전 통로 개방 |
| 스이쿤 | 분노의호수에서 하류로 흘러간 오염을 정화 | 상류 유입을 끊고 강변 포켓몬 구조 | 물빛·물가 NPC·낚시 서식지 변화 |

불탄탑에서 칠색조의 전승을 듣지만 과거 사건의 전모를 영상으로 확정하지 않는다. 방울탑에서는 강제 부활 실험을 막는다. 칠색조는 새로운 생명을 대량 생산하는 장치가 되지 않는다. 루기아는 소용돌이섬의 흐름을 어지럽히는 시설을 경계하며, 주인공이 시설을 멈춰 접근할 여지를 만든다.

본편의 세 전설은 목격·추적 중심이다. 끝없이 도망치는 포획 로밍은 엔딩 후 선택 모드로 둔다. 추적 단서를 일정 수 모으면 고정 조우도 가능하게 하여 이동 운만으로 완수를 막지 않는다.

### 하나편과 라이벌

유진은 포켓몬을 해치는 실험에 동의해서 합류하지 않는다. 구조 사업의 성과를 보고 조사에 참여했다가, 아크가 주민의 반대 의견을 데이터에서 제거한 사실을 발견한다. 주인공과의 대립 전투는 “누가 악당인가” 판정이 아니라 서로의 판단을 시험하는 장면이다.

레시라무와 제크로무 중 어느 쪽이 주인공에게 응답하는지는 두 선택지 중 하나로 연출할 수 있다. 반대편은 유진에게 응답한다. 도덕 점수나 우열을 부여하지 않으며 두 종 모두 엔딩 후 획득할 수 있다. 본편의 응답은 임시 동행 연출로 처리하고 파티 슬롯이나 소유 상태로 취급하지 않는다.

용의 분열·공백에 관한 기록으로 큐레무를 예고하되 본편의 또 다른 최종 보스로 추가하지 않는다. 큐레무 후일담은 양쪽 용의 사건이 끝난 뒤 독립적으로 열린다.

### 최종장: 플레이어가 마지막까지 할 일

1. 신오 각 도시에서 구조 경로를 확보한다. 관장들은 체육관 밖에서 실제로 대피를 돕는다. 배지는 대응 훈련의 증거이며 재난 중 경기를 강요하는 유일한 통행증이 아니다.
2. 창기둥에서 서진과 대립한다. 앞선 장에서 파괴된 회로 때문에 장치가 불안정하며, 조직은 이 위험을 알고도 계속했다.
3. 디아루가·펄기아의 충돌로 깨어진세계 입구가 열린다. 기라티나는 균열을 추적해 개입하며 주인공에게 자동 복종하지 않는다.
4. 깨어진세계에서 관동의 기록, 성도의 상처, 하나의 선택, 신오의 길이 네 구역으로 나타난다. 각 구역의 길·사물 퍼즐을 풀어 접점을 분리한다.
5. 뮤츠는 관동에서 보았던 주인공의 행동을 믿고 정신 간섭을 막는다. 하린·지역 관장들은 바깥의 중계기를 차단하고 유진은 동료들의 출구를 확보한다.
6. 서진은 원상복구가 자신이 잃은 것을 되돌리지 못함을 받아들이고 비상 해제에 협력한다. 마지막 스위치와 귀환 경로 확보는 플레이어가 수행한다.
7. 디아루가·펄기아와 기라티나가 경계를 안정화한다. 동료들의 행동이 맞물렸기 때문에 가능한 결말이다.

뮤츠의 대사 초안: “나를 만든 이유가, 내가 살아갈 이유는 아니다.”

엔딩은 하나다. 용 선택·따라큐의 거처·선택 퀘스트에 따라 편지, 마을 모습, 도와주는 NPC가 달라진다. 선택 퀘스트를 놓쳤다고 세계가 파괴되는 배드엔딩이나 돌이킬 수 없는 도감 누락을 만들지 않는다. 대사는 실제 제작 시 현재 대화창 크기에 맞춰 나눈다.

## 6. 체육관·리그·육성 흐름

32개 체육관의 도시·타입·ID·순서는 [맵 문서](개발용_초안맵.md)의 체육관 표를 기준으로 한다.

| 진행 구간 | 필수 체육관 | 신규 필수 수 / 누적 | 권장 레벨 초안 |
| --- | --- | --- | --- |
| 신오 전반 | 무쇠·영원·연고·장막 | 4 / 4 | 5~23 |
| 관동 | 회색·블루·갈색·무지개 | 4 / 8 | 24~34 |
| 성도 | 도라지·고동·금빛·인주 | 4 / 12 | 35~42 |
| 하나 | 구름·뇌문·물풍경·쌍용 | 4 / 16 | 43~50 |
| 신오 후반 | 들판·운하·선단·물가 | 4 / 20 | 51~60 |
| 창기둥·깨어진세계 | 추가 배지 없음 | 20~32개 보유 가능 | 61~68 |
| 지역 리그 | 해당 지방 배지 8개 + 사건 엔딩 | 지방별 독립 제패 | 68~78 |
| 월드 마스터즈 | 32개 배지 + 4개 지역 리그 제패 | 대회 우승 별도 기록 | 80~90 |

위 수치는 밸런스 검증 전의 기준점이다. 고정 100레벨을 조기에 요구하지 않는다. 이야기 진행은 핵심 배지의 **개별 ID**로 검사하며 다른 지방의 쉬운 선택 배지로 대체하지 않는다.

선택 체육관은 그 지방에 도착한 뒤 방문할 수 있다. 이야기 때문에 방문 자체가 늦는 선단 등의 구역과 구분한다. 각 관장은 현재 장에 대응하는 사전 정의 팀을 사용하고 전투 접수 때 팀을 고정한다. 파티 최고 레벨에 실시간으로 따라오거나 배지를 얻은 뒤 취소하지 않는다. 선택 콘텐츠의 추가 경험치로 본편을 쉽게 만드는 것은 허용한다.

야생 레벨은 서식지 구간별 고정표를 쓴다. 후반에 새로 잡은 낮은 레벨의 포켓몬은 훈련 의뢰·재대결로 따라잡게 한다. 전투·육성 수치의 자동 보정은 별도 설계 대상이며 현재 코드에 있다고 가정하지 않는다.

관동·성도는 석영고원 시설을 공동 사용하되 **관동 대회와 성도 대회 두 운영 일정**을 둔다는 창작 설정이다. 같은 사천왕을 이름만 바꿔 두 번 상대하게 하지 않고 대회별 명단·전술을 따로 정한다. 신오·하나는 별도 리그 시설을 쓴다. 사건 엔딩과 챔피언 엔딩은 구분한다.

## 7. 포켓몬별 주요 사이드스토리

모든 퀘스트는 다시 방문해 완료할 수 있다. 요일·시간은 분위기를 바꾸는 조건으로 쓰되 게임 안 휴식 또는 다음 회차 예약으로 재도전 시간을 제공한다. 현실의 금요일 밤을 일주일 기다려야만 도감을 채우는 방식은 기본안에서 제외한다.

### SQ01 피카츄 마을 — 작은 불빛들의 숲

- 장소: 관동 상록숲의 숨은 분기 K05. 진입: CH03부터, 숲길에서 열매 흔적을 따라 발견.
- 시작: 피츄 놀이터, 열매 창고, 서로 볼을 맞대는 피카츄의 생활을 먼저 보여준다. 장치를 끄는 일보다 이 마을을 기억하게 한다.
- 행동: 지친 피츄를 쉬게 할 장소 찾기 → 나무뿌리 아래 축전기 탐색 → 장치 해제 → 안내등 되살리기.
- 결과: 마을 생활 연출 복구, 전기구슬과 수선용 천 조각. 피츄를 맡는 제안은 선택이며 거절 후 재수락 가능.
- 연결: 라이코 사건에서 동일한 장치 표식을 알아본다. 피카츄를 파티에 두면 추가 인사 연출만 발생한다.
- 본편 필수 아님. 피카츄 미수령·다른 스타팅·마을 미발견 모두 메인 진행 가능.

### SQ02 이브이 — 여덟 개의 길

- 시작: 하린의 소개를 받아 무지개시티 프리즘 하우스 K08 방문. 새 이브이 한 마리를 위탁받는다. 연구소의 기존 이브이를 삭제하지 않는다.
- 목적: 한 마리를 여덟 번 되돌려 진화시키는 일이 아니라 **8종의 진화 사례를 관찰하거나 직접 기르는 연구**다.
- 관동: 샤미드·쥬피썬더·부스터의 진화 도구. 성도: 에브이·블래키의 친밀도와 낮·밤. 신오: 리피아·글레이시아의 숲·설원 장소. 하나: 님피아의 친밀도와 페어리 기술.
- 모두 해금해도 플레이어가 원하는 진화를 강요하지 않는다. 진화 취소·보류, 필요한 도구 확인, 경쟁 조건 우선순위를 UI에서 먼저 설명한다.
- 기본 제안: 도구·장소는 명시적인 사용/상호작용, 친밀도 계열은 조건 충족 후 진화 제안. 에브이·블래키·님피아 조건이 겹치면 희망 진화 선택 후 확정한다. 이 작품의 편의 규칙이다.
- 두 번째 이후 이브이는 연구 신뢰 확보 후 보호구역의 반복 가능한 조우로 얻는다. 모든 진화형을 한 저장에서 수집 가능하다.
- 보상: 프리즘 하우스의 8개 생활 공간 완성, 연구가의 편지, 진화 도구 재구매. 본편 필수 조건으로 사용하지 않는다.

### SQ03 따라큐 — 천 아래의 친구

- 장소: 보라타운 장난감 수선방 K11. 밤에 피카츄처럼 생긴 그림자를 목격.
- 1막: 위치가 달라지는 인형과 바닥의 실밥을 따라간다. 처음에는 겁주는 분위기지만 천 아래를 강제로 벗기거나 촬영하지 않는다.

- 4막: 천을 맡길 수 있도록 열매를 놓고 기다린다. 쫓아가거나 먼저 쓰러뜨려야 신뢰가 오르는 구조는 쓰지 않는다.

## 9. 등장 포켓몬 수록 원칙

사용자가 붙인 2020·2021·2016 목록은 중복 종을 합쳐 관리한다. **전 종의 이름·장소·획득법을 맵 문서의 수록표에 적는다.** 진화형을 수록하려면 진화 전 종, 도구, 시간·친밀도 조건도 함께 구현해야 한다.

- 일반 야생, 구조 의뢰, 육성·진화, 고정 희귀 조우, 전설 후일담을 나눈다. 관장 에이스로 보이는 것만으로 획득 계획을 대신하지 않는다.
- 후대 포켓몬도 초중반의 항구·교류원·보호구역에서 만날 수 있다. 모든 낯선 포켓몬을 아크의 실험체로 설명하지 않는다.
- 개굴닌자·모크나이퍼·인텔리레온 등 최종 진화형은 대체로 진화 전 종부터 함께 성장한다. 시작 연구소 선택지는 유지한다.
- 일반 색·색이 다른 모습·지역 모습·전투 변신은 별도 구분한다. 기본 종의 등장 약속에 메가진화·거다이맥스·특수 변신까지 자동 포함하지 않는다.
- 매시붕은 울트라비스트 특별 탐사로 분류한다. 모든 희귀 포켓몬을 전설이라고 부르지 않는다.
- 일반 교환 진화는 게임 내 NPC 교환·진화 도구 대체 경로를 제공한다. 랭킹에 진화 전·후가 함께 있으면 양쪽을 실제 도감 종으로 등록한다.

| CH00~CH10 장 완료 | 미완료 / boolean 집합 | 해당 장의 모든 필수 결과 확정 후 | 최고 장 숫자 하나로 선택 퀘스트까지 완료 처리하지 않음 |

| 교통 노선 해금 | 미개통 / boolean 집합 | 첫 출발 접수 전 왕복 권한 확정 | 도착 후에도 되돌아올 수 있음 |
| SQ별 단계 | 미발견 / 유한 숫자 단계 | 조사·구조·선택 확정 시 | 대화 콜백을 저장하는 대신 완료된 단계부터 복원 |
| 사건 해결과 보상 수령 | 각각 false / 별도 boolean | 사건 확정, 보상 지급 성공을 각각 기록 | 파티·보관함이 가득 차면 미수령 상태로 대기 |
| 따라큐 거처 | 미정 / 숫자 열거 후보 | 거처 선택 후 | 거처와 소유 상태를 혼동하지 않으며 후일 여행 제안 가능 |
| 용의 응답 선택 | 미정 / 숫자 열거 후보 | CH07 선택 확정 | 반대 용의 도감·포획 경로를 잠그지 않음 |
| 전설 사건·포획 | 각각 false / 별도 상태 | 해결 성공과 개체 지급 성공을 구분 | 실패는 재도전, 잡은 개체는 중복 생성 금지 |
| 변형 맵 상태 | 기본 / 장에 따른 상태 | 안전한 전환점에서 확정 | 구 버전 좌표가 막히면 사전 정의 안전 지점으로 이동 |

본편을 진행시키는 보상은 단 하나의 희귀 야생 포켓몬 보유나 현실 요일에 의존하지 않는다. 퀘스트 도구를 버릴 수 있게 만들 경우 반드시 재발급 경로를 둔다. 깨어진세계 진입 전 상태, 보스 패배 시 복귀점, 이벤트 도중 저장 후 재개점을 설계해야 한다.

수령 플래그는 과거 지급 이력이다. 피카츄가 라이츄로 진화하거나 기존 스타팅을 보관함에 맡겨도 `pikachuReceived`·`starterReceived`를 지우지 않는다. 개체의 현재 종·소유 위치와 지급 이력을 분리해 저장 검증을 확장하고, 연구소 재방문으로 같은 선물을 다시 받는 문제가 없도록 한다.

현재 세이브 검사는 레벨 5·4종·제한된 파티만 허용한다. 이 초안의 육성과 도감을 추가할 때는 `src/save.ts`·`src/pokemon.ts`·`src/types.ts`·파티 및 요약 UI를 함께 확장하고 이전 유효 저장을 이행해야 한다. 문서만 추가한 이번 작업에서는 저장 버전을 바꾸지 않는다.

## 11. 개발 순서와 수용 기준

| 단계 | 구현할 최소 구간 | 통과해야 다음 범위를 착수 |
| --- | --- | --- |
| D0 기준 보존 | 현재 첫 파트너 구간 | 기존 수령 순서·저장·이동 회귀 통과 |
| D1 첫 모험 | 새잎 서쪽 첫 도로, 야생 1종, 기본 전투·포획·회복 | 이동→전투→복귀, 패배·도주·저장 복구를 실제 플레이로 확인 |
| D2 첫 배지 | 무쇠까지의 작은 동선, 관장 1명 | 초반 파티별 클리어 가능, 배지·보상 중복 없음 |
| D3 신오 전반 | 핵심 4체육관과 운하 출항 | 통과 순서·재방문·항구 귀환, 이야기 이해와 길 찾기 확인 |
| D4 관동 | 핵심 4체육관 + 피카츄·이브이·따라큐 중 우선 에피소드 | 필수와 선택 동선 모두 막힘 없음, 수록 종 획득·저장 가능 |
| D5 성도·하나 | 지역별 본편, 교통, 해당 종과 체육관 | 이전 지방 파티 유지·왕복·선택 퀘스트 복구 |
| D6 신오 귀환·엔딩 | 변형 맵, 깨어진세계, 최종 사건 | 변형 전후 안전 좌표·귀환, 20배지 최소 경로로 엔딩 |
| D7 후일담 | 남은 체육관·4리그·전설·목록 잔여 종 | 단일 저장에서 수록 목록 전 종 획득 가능 |

이 표는 작업 분할이며 자동 구현 지시가 아니다. 첫 마을만 존재하는 현재 시점에서 4개 지방 전체를 동시에 코딩하지 않는다.

실제 구현의 수용 기준은 자동 테스트·`npm.cmd run build`·고유 `?qa=` 브라우저 플레이를 구분해 기록한다. 초안 문서 검사는 장/배지 합계, 장소 참조, 포켓몬 누락, 링크, 저장 계약과의 모순을 확인한다. 현재 테스트 통과를 미래 RPG 전체의 검증으로 보고하지 않는다.

## 12. 후속 결정 목록

1. 장기 제목 NEXUS, 팀 아크와 새 인물 이름을 최종 채택할지 결정한다.
2. 기본 32체육관은 지방별 타입을 유지하되 관장 본인·후계자·새 인물의 비율을 결정한다.
3. 단일 전투 규칙 세대, 페어리 타입, 기술·특성·진화 도구의 수록 범위를 확정한다. 특수 전투 변신은 별도 범위다.
4. 육성 속도와 선택 체육관 팀 표는 첫 2개 체육관의 실제 플레이 이후 보정한다.
