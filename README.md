# Pokémon Nexus

Nintendo DS DP/플라티나풍 포켓몬 팬게임 프로젝트.

지역별 야생 포켓몬·첫 진화·기술 교체·박스/도감, 도시 사이 통로와 상점·층별 실내를 플레이에 연결했습니다. [이번 구현과 검증, 남은 범위](docs/JOURNEY_IMPLEMENTATION.md)에서 확인할 수 있습니다.

## 실행

```powershell
npm.cmd install
npm.cmd run dev
```
